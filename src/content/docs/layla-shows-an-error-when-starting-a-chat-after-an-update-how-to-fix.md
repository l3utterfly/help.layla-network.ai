Sometimes, during model loading or after an update, you may see an error like this:

![REPL error shown while a Layla model is loading.](/assets/articles/layla-shows-an-error-when-starting-a-chat-after-an-update-how-to-fix/model-load-error.png)

These errors can usually be fixed by going to the *Settings* page, scrolling down, and selecting *Clear cache*.

It is very rare for an error to require downloading the models or app again. Clearing the cache is designed to reset the app to a clean state.

Note: after you clear the cache, characters will load slowly the first time.
