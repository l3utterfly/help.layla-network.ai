Layla kann die Antworten Ihres Charakters laut vorlesen. Dafür gibt es drei Wege, und jeder eignet sich für eine andere Situation: eine freihändige gesprochene Unterhaltung, das automatische Vorlesen jeder Antwort, während Sie weiter tippen, oder das Vorlesen einer bestimmten Nachricht auf Wunsch.

Bevor eine dieser Möglichkeiten Ton erzeugt, benötigt Ihr Charakter eine Stimme. Falls Sie noch keine eingerichtet haben, lesen Sie [So verwenden Sie PocketTTS in Layla](/how-to-use-pockettts-in-layla/) oder [So fügen Sie Ihren Charakteren in Layla mehrsprachige Sprachausgabe hinzu](/how-to-add-multilingual-text-to-speech-for-your-characters-in-layla/).

## Einen Sprachchat starten

Der Sprachchat ist eine freihändige, gesprochene Unterhaltung in beide Richtungen. Layla hört Ihnen zu, wandelt Ihre Sprache in Text um, erzeugt eine Antwort und liest diese laut vor. Bei einem animierten Charakter bewegen sich die Lippen des Charakters synchron zur Stimme.

Um ihn zu starten, öffnen Sie einen Chat und tippen Sie in der Nachrichtenleiste neben dem Eingabefeld auf das **Wellenform-Symbol**. Layla wechselt in den Sprachchat-Modus und zeigt während des Starts _Sprachchat wird initialisiert..._ an.

![Bildschirmfüllender Sprachchat mit einem animierten Charakter. Unten befindet sich eine rote Schaltfläche „Sprachchat beenden“, links eine Plus-Schaltfläche und rechts eine Pause-Schaltfläche.](./voice-chat.jpg)

Sobald die Mikrofon-Schaltfläche grün wird, können Sie sprechen. Wenn Sie aufhören, geben Sie Layla einen Moment, um das Gesagte zu verarbeiten; anschließend antwortet sie laut. Im Sprachchat-Modus stehen Ihnen einige Bedienelemente zur Verfügung:

- **Pausieren und fortsetzen** — unterbrechen Sie die Unterhaltung und setzen Sie sie fort, wenn Sie bereit sind.
- **Zum Weitersprechen gedrückt halten** — halten Sie die Taste gedrückt, wenn Sie mehr Zeit brauchen, um einen Gedanken zu Ende zu führen, bevor Layla antwortet.
- **Sprachchat beenden** — die rote Schaltfläche beendet den Sprachchat-Modus und bringt Sie zur normalen Textansicht zurück.

Für eine gute Erkennung sprechen Sie deutlich und wählen Sie einen ruhigen Raum. Hintergrundgeräusche können den Schritt der Spracherkennung stören.

## Antworten automatisch vorlesen lassen

Wenn Sie lieber weiter tippen, aber jede Antwort beim Eintreffen hören möchten, aktivieren Sie das automatische Vorlesen. Das ist nicht dasselbe wie der Sprachchat: Sie schreiben Ihre Nachrichten weiterhin, und Layla liest lediglich jede Antwort vor.

1. Tippen Sie in einem Chat auf die **Plus-Schaltfläche** links neben der Nachrichtenleiste, um das Menü **Chat-Aktionen** zu öffnen.
2. Tippen Sie auf **Antworten vorlesen**.

![Das Menü Chat-Aktionen mit Bild, Kamera, Datei, Referenz, Push-to-Talk, Schnellbefehle, Antworten vorlesen und Anweisung hinzufügen. Die Option Antworten vorlesen ist hervorgehoben und damit aktiv.](./speak-responses.jpg)

Ist die Option aktiv, wird sie hervorgehoben dargestellt. Ab diesem Zeitpunkt wird jede neue Antwort Ihres Charakters automatisch vorgelesen. Zum Ausschalten öffnen Sie erneut die Chat-Aktionen und tippen ein zweites Mal auf **Antworten vorlesen**; die Hervorhebung verschwindet und Layla liest neue Antworten nicht mehr vor.

## Eine einzelne Nachricht vorlesen lassen

Manchmal möchten Sie nur eine bestimmte Nachricht hören, statt das Vorlesen für alles einzuschalten. Das funktioniert bei jeder Nachricht der Unterhaltung, ob alt oder neu.

1. Halten Sie die Nachricht gedrückt, die Sie hören möchten. Bei der neuesten Antwort können Sie stattdessen die Schaltfläche **Mehr (...)** an der Nachricht antippen.
2. Tippen Sie im erscheinenden Menü auf **Vorlesen**.

![Das Aktionsmenü einer Nachricht mit den Optionen Kopieren, Bearbeiten, Neu generieren, Fortsetzen, Löschen, Vorlesen, Bild generieren und Übersetzen.](./speak.jpg)

Layla liest genau diese eine Nachricht vor. Sonst ändert sich nichts: Das automatische Vorlesen bleibt ausgeschaltet, und Sie können dies bei beliebig vielen einzelnen Nachrichten verwenden.

## Welche Variante sollte ich verwenden?

- Verwenden Sie den **Sprachchat** für eine vollständig gesprochene Unterhaltung ohne Tippen.
- Verwenden Sie **Antworten vorlesen**, wenn Sie tippen, aber jede Antwort hören möchten.
- Verwenden Sie **Vorlesen** bei einer Nachricht, wenn Sie nur eine bestimmte Antwort hören möchten.

Alle drei nutzen dieselbe Sprachausgabe-Stimme, die Sie für den Charakter eingerichtet haben. Eine gute Stimme einzurichten verbessert daher den Klang bei jeder dieser Möglichkeiten.
