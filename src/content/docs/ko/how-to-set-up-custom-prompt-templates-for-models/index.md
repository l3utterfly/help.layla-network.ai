사용자 지정 프롬프트 템플릿은 캐릭터 설명, 지시, 대화 기록, 사용자 메시지, 모델 응답을 AI 모델에 보내기 전에 Layla가 어떤 순서와 구조로 배치할지 정의합니다. 모델 자체를 변경하는 설정은 아닙니다. Layla의 대화를 모델이 학습 과정에서 익힌 정확한 구조로 변환하는 역할을 합니다.

Layla에 포함된 모델에는 이미 적절한 프롬프트 설정이 적용되어 있습니다. 일반적으로 사용자 지정 모델을 추가하거나 Layla가 모델에 지시하는 방식을 의도적으로 바꾸려는 경우에만 이 설정을 변경하면 됩니다. 아직 모델을 가져오지 않았다면 먼저 [Layla에 사용자 지정 AI 모델을 추가하는 방법](/ko/how-to-add-custom-models-to-layla/)을 확인하세요.

## 프롬프트 템플릿이 모델과 일치해야 하는 이유

각 채팅 모델은 특정 프롬프트 형식을 전제로 작동합니다. 예를 들어 ChatML, Llama, Gemma, Mistral 또는 그 밖의 모델 계열별 형식을 사용할 수 있습니다. 형식마다 시스템 메시지, 사용자, 어시스턴트, 각 턴의 끝을 구분하는 마커가 다릅니다.

올바른 형식은 단순히 GGUF 파일 형식이 아니라 모델이나 파인튜닝 방식에 따라 결정됩니다. 두 GGUF 모델에 서로 다른 템플릿이 필요할 수 있으며, 같은 아키텍처를 기반으로 한 모델도 서로 다른 채팅 형식으로 학습되었을 수 있습니다.

로컬 모델을 선택하면 Layla가 파일 이름을 바탕으로 적합해 보이는 프롬프트 프리셋을 자동 선택할 수 있습니다. 이 선택은 출발점으로만 사용하세요. 모델 카드나 다운로드 페이지에서 **prompt format**, **chat template**, **instruct template** 같은 항목을 찾은 뒤, Layla에서 선택된 프리셋과 일치하는지 확인해야 합니다.

잘못된 템플릿을 사용하면 모델이 다음과 같이 동작할 수 있습니다.

- 캐릭터 설명이나 시스템 지시를 무시함
- 응답에 특수 마커를 그대로 출력함
- 멈추지 않고 사용자 역할의 내용까지 이어서 작성함
- 사용자 메시지와 어시스턴트 메시지를 혼동함
- 짧거나 반복적이거나 구조가 어색한 응답을 생성함

모델, 양자화 및 모델 카드에 관한 자세한 내용은 [GGUF란 무엇인가요? GGUF 모델을 쉽게 설명하는 가이드](/ko/what-are-gguf-models-what-are-model-quants/)를 참고하세요.

## 내 프롬프트를 열고 선택된 형식 확인하기

Layla의 **설정** 페이지에서 **추론 설정**을 열거나 **추론 설정** 미니 앱을 직접 실행합니다. 선택된 모델은 **내 모델**에 표시되고, 활성 프롬프트 형식은 바로 아래의 **내 프롬프트**에 표시됩니다.

아래 예시에서는 Gemma 4 모델이 선택되어 있고 **Gemma 4**가 활성 프롬프트입니다. **사용자 지정 프롬프트 추가** 카드는 새 형식을 만들며, 활성 프롬프트의 전환 버튼은 사용 가능한 형식 목록을 엽니다.

![로컬 GGUF 모델과 사용자 지정 프롬프트 템플릿을 추가하거나 전환하는 컨트롤이 표시된 Layla 추론 설정.](./infsettings.jpg)

활성 프롬프트의 전환 버튼을 눌러 **프롬프트 선택**을 엽니다. ChatML, Llama 3, Phi, OpenELM, Gemma 같은 기본 제공 형식과 저장한 사용자 지정 프롬프트가 함께 표시됩니다. 활성 형식은 파란색으로 강조됩니다.

![ChatML, Llama 3, Phi, OpenELM, Gemma, Gemma 4 형식이 표시된 Layla 프롬프트 템플릿 선택 화면.](./selectprompt.jpg)

모델 문서에서 이 목록에 있는 형식을 지정한다면 해당 항목을 눌러 별도의 생성 과정 없이 프리셋을 사용하세요. 목록에 없는 변형이 필요하거나 모델의 필수 형식을 유지하면서 자체 지시를 추가하려는 경우에는 사용자 지정 프롬프트를 만듭니다.

## 사용자 지정 프롬프트 만들기

**내 프롬프트**에서 **사용자 지정 프롬프트 추가**를 누르면 편집기가 열립니다. 편집기 상단에는 가로로 스크롤할 수 있는 **프리셋** 목록이 있습니다. 프리셋을 누르면 해당 형식이 아래 필드에 복사됩니다. 모든 구분자를 직접 입력하는 것보다 안전한 출발점입니다.

![프리셋에서 사용자 지정 LLM 프롬프트 템플릿을 만들고 시스템 프롬프트를 설정하는 Layla 프롬프트 편집 화면.](./editprompt.jpg)

1. **프리셋**에서 모델에 필요한 형식과 가장 가까운 항목을 선택합니다.
2. 알아보기 쉬운 **프롬프트 이름**과 **프롬프트 설명**을 입력합니다. 나중에 **프롬프트 선택**에서 비슷한 사용자 지정 형식을 구별하는 데 도움이 됩니다.
3. **시스템 프롬프트**와 **서식**까지 스크롤한 다음, 다음 섹션에서 설명하는 필드를 조정합니다. 모델에서 요구하는 특수 마커, 줄바꿈, 공백은 그대로 유지하세요.
4. **사용 가능한 템플릿**과 **실시간 미리보기**까지 내려가 완성된 형식이 어떻게 조합되는지 확인합니다.
5. **프롬프트 저장**을 누릅니다. 저장한 프롬프트는 현재 추론 설정에 즉시 적용되며 나중에 다시 사용할 수 있습니다.

## 시스템 및 서식 필드 설정하기

**시스템 프롬프트 시작**과 **시스템 프롬프트 끝** 아래에는 빨간색 **시스템 프롬프트 비활성화** 스위치가 표시되고, 그다음에 **중지 문구**, **입력 접두사**, **입력 접미사**, **컨텍스트 접두사**가 이어집니다. 일반 채팅 모델을 설정할 때는 **시스템 프롬프트 비활성화**를 끈 상태로 두세요.

![시스템 프롬프트 비활성화와 중지 문구, 입력 접두사, 입력 접미사, 컨텍스트 접두사를 설정하는 Layla 사용자 지정 프롬프트 설정.](./disablesys.jpg)

Layla는 이 필드들을 사용해 대화를 여러 섹션으로 조립합니다. 간단히 말하면 시스템 블록 안의 캐릭터 정보로 시작한 뒤, 인사말, 대화 기록, 앱에서 제공한 컨텍스트, 최신 사용자 메시지, 모델에 응답 시작을 알리는 마커를 차례로 추가합니다.

| 설정                     | 역할                                                                                                                                              |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| **시스템 프롬프트 시작** | Layla의 캐릭터 설명, 성격, 시나리오 및 기타 시스템 수준 정보 바로 앞에서 시스템 섹션을 엽니다.                                                    |
| **시스템 프롬프트 끝**   | 대화가 시작되기 전에 시스템 섹션을 닫습니다. 대부분의 프리셋은 여기에 `{{instruction}}`도 포함합니다.                                             |
| **중지 문구**            | 어시스턴트 턴의 끝을 표시합니다. Layla는 이를 사용해 생성을 중지하고 완료된 메시지를 구분합니다. 안티 프롬프트 또는 리버스 프롬프트라고도 합니다. |
| **입력 접두사**          | 각 사용자 메시지 앞에 표시되어 사용자 턴의 시작을 알립니다.                                                                                       |
| **입력 접미사**          | 사용자 메시지 뒤에 표시됩니다. 일반적으로 사용자 턴을 닫고 어시스턴트 턴을 열어 모델이 응답해야 함을 알립니다.                                    |
| **컨텍스트 접두사**      | 불러온 정보나 Agent 결과처럼 Layla 기능이 삽입한 추가 컨텍스트를 소개하여 모델이 사용자 메시지와 구분할 수 있도록 합니다.                         |

시작과 끝 필드는 Layla가 제공하는 내용을 감싸는 용도입니다. 캐릭터 설명 전체를 여기에 붙여 넣지 마세요. 캐릭터 세부 정보는 캐릭터 편집기에서 설정하고, 프롬프트 필드는 그 정보를 모델에 어떻게 제시할지 정의합니다. 캐릭터 설정 방법은 [사용자 지정 캐릭터를 만드는 방법](/ko/how-do-i-create-custom-characters/)을 참고하세요.

**중지 문구**와 **입력 접미사**는 관련되어 있지만 서로 바꿔 사용할 수는 없습니다. 중지 문구는 어시스턴트 응답이 끝나는 위치를 Layla에 알려 줍니다. 입력 접미사는 사용자의 입력이 끝났고 어시스턴트의 응답이 시작되어야 함을 모델에 알려 줍니다. 일부 형식에서는 같은 구분자의 일부를 공유하지만, 각 필드는 모델 문서의 템플릿을 따라야 합니다.

### 시스템 프롬프트를 비활성화해야 하는 경우

**시스템 프롬프트 비활성화**는 Layla가 캐릭터 설명과 기타 시스템 프롬프트 내용을 보내지 않도록 합니다. 고급 호환성 옵션이며, 프롬프트를 짧게 만드는 일반적인 방법이 아닙니다.

모델이나 서비스가 시스템 프롬프트를 지원하지 않거나 문서에서 지시를 다른 위치에 넣도록 명시한 경우에만 활성화하세요. 시스템 프롬프트를 비활성화하면 캐릭터의 정체성이 제거되고 시스템 수준 지시에 의존하는 앱이 제대로 작동하지 않을 수 있습니다.

클라우드 및 API 모델은 공급자가 다른 요구 사항을 명시하지 않는 한 Layla의 **Cloud** 프롬프트로 시작하세요. 클라우드 서비스는 일반적으로 서버에서 역할 형식을 처리하므로 로컬 모델용 구분자를 API 연결에 추가할 필요가 없습니다.

## 플레이스홀더 사용 및 실시간 미리보기 확인하기

계속 아래로 스크롤하면 **사용 가능한 템플릿**이 표시됩니다. 이 영역에는 실행 중 Layla가 치환할 수 있는 플레이스홀더가 나열됩니다. 바로 아래의 **실시간 미리보기**는 캐릭터, 사용자, 응답, 구분자의 예시를 결합하여 프롬프트의 각 부분이 의도한 순서로 배치되는지 보여 줍니다.

![사용자, 캐릭터, 지시, 시간용 사용자 지정 프롬프트 플레이스홀더와 실시간 미리보기가 표시된 Layla 화면.](./templates.jpg)

미리보기에서는 캐릭터 정보가 파란색, 사용자 메시지가 흰색, 응답이 녹색, 모델 구분자가 회색으로 표시됩니다. 역할 마커가 빠졌거나 접두사 또는 접미사가 잘못 배치되었는지 확인하는 데 사용할 수 있습니다. Layla가 섹션을 조립하는 방식은 보여 주지만, 필요한 형식은 모델 카드와도 반드시 대조하세요.

### `{{instruction}}`의 작동 방식

추론 전에 `{{instruction}}`은 현재 작업에 맞는 지시로 치환됩니다. 일반 캐릭터 채팅에서는 선택한 사용자 페르소나와 캐릭터를 식별하고 모델이 해당 캐릭터를 완전히 연기하도록 지시합니다. 다른 Layla 기능에서 작업별 지시를 제공할 수도 있습니다. 장기 기억, Dreams, Lorebooks 및 기타 앱은 프롬프트를 준비할 때 이러한 지시를 사용할 수 있습니다.

`{{instruction}}`은 세 가지 방식으로 사용할 수 있습니다.

- **Layla의 지시를 그대로 유지:** 템플릿에 `{{instruction}}`을 남겨 둡니다. 자체 지시를 제공하는 기능과의 호환성을 유지하는 가장 안전한 방법입니다.
- **Layla의 지시에 내용 추가:** `{{instruction}}` 앞이나 뒤에 자연어로 된 자체 지시를 작성합니다. Layla의 작업별 지시와 추가 규칙이 모두 삽입됩니다.
- **완전히 교체:** `{{instruction}}`을 제거하고 그 자리에 자체 지시를 작성합니다. Layla는 작성한 내용을 사용하지만, 일반적으로 이 플레이스홀더에 들어가는 기능별 지시는 더 이상 포함되지 않습니다.

예를 들어 `{{instruction}}` 뒤에 짧은 문체 규칙을 추가하면 Layla의 캐릭터 및 앱 지시를 유지할 수 있습니다. 플레이스홀더를 완전히 제거했다면 일반 채팅뿐 아니라 사용하는 모든 기능을 테스트하세요.

`{{instruction}}`을 사용자가 입력한 텍스트와 혼동하지 마세요. Layla가 프롬프트를 구성할 때 치환되며 별도의 채팅 메시지로 표시되지 않습니다.

### 기타 사용 가능한 플레이스홀더

같은 **사용 가능한 템플릿** 영역에는 다음 세 가지 플레이스홀더도 표시됩니다.

- `{{user}}`는 선택된 페르소나 이름으로 바뀝니다.
- `{{char}}`는 캐릭터 이름으로 바뀝니다.
- `{{time}}`은 기기의 현재 날짜와 시간으로 바뀝니다.

플레이스홀더는 모델 제어 토큰이 아닙니다. Layla는 플레이스홀더를 현재 정보로 치환하지만, 모델 제어 토큰은 모델의 채팅 형식에서 요구하는 정확한 특수 마커입니다. 플레이스홀더 이름은 대소문자를 구분하지 않지만 모델의 제어 토큰은 구분할 수 있습니다.

`{{user}}`와 `{{char}}`는 화자 이름을 사용해 학습된 역할극용 파인튜닝 모델에서 유용할 수 있습니다. 일반적인 Instruct 모델에서는 “user”와 “assistant” 같은 고정 역할이 학습 형식에 더 잘 맞을 수 있습니다. 개인 취향만으로 역할 이름을 바꾸지 말고 모델 카드의 지침을 따르세요.

## 프롬프트 템플릿 테스트하기

프롬프트를 저장한 후 새 채팅을 시작하고 다음과 같이 간단히 확인합니다.

1. 캐릭터에게 자신을 소개해 달라고 요청합니다. 시스템 정보와 캐릭터 정보가 제대로 이해되었는지 확인할 수 있습니다.
2. 메시지를 두세 번 보내 모델이 사용자와 어시스턴트 역할을 분리해서 유지하는지 확인합니다.
3. 응답이 정상적으로 끝나고 처리되지 않은 제어 토큰이 포함되지 않는지 확인합니다.
4. 기억, Lorebooks, Dreams, 역할극, Agent 등 평소 사용하는 Layla 기능을 실행합니다.

모델이 올바르게 작동하지 않으면 각 필드를 해당 모델에 게시된 정확한 템플릿과 비교하세요. 특히 제어 토큰 주변의 줄바꿈에 주의해야 합니다. 눈에 보이지 않는 서식 차이도 모델이 프롬프트를 해석하는 방식에 영향을 줄 수 있습니다.

## 일반적인 문제

### 모델이 사용자를 대신해 말합니다

중지 문구, 입력 접두사 또는 입력 접미사가 모델과 일치하지 않을 가능성이 높습니다. 올바른 프리셋을 다시 선택하고 모델 카드와 비교하세요.

### 응답에 역할 이름이나 꺾쇠괄호로 둘러싸인 토큰 같은 마커가 표시됩니다

모델이 인식하지 못하는 형식을 받고 있거나 중지 문구가 완전하지 않습니다. 해당 파인튜닝에 사용된 정확한 채팅 템플릿을 확인하세요.

### 캐릭터의 성격이 무시됩니다

**시스템 프롬프트 비활성화**가 꺼져 있고 시스템 프롬프트의 시작 및 끝 마커가 올바른지 확인하세요. 모델이 시스템 지시를 지원하는지도 확인해야 합니다.

### 기억, Lorebooks 또는 다른 앱이 응답에 영향을 주지 않습니다

`{{instruction}}`을 복원하거나 사용자 지정 지시 옆에 다시 추가하세요. 컨텍스트 접두사가 선택한 모델에 적합한지도 확인합니다.

### 한 모델에서는 작동하는 프롬프트가 다른 모델에서는 작동하지 않습니다

모델이 서로 다른 채팅 템플릿을 사용한다면 정상입니다. 각 형식에 대해 이름이 다른 프롬프트를 저장하고 모델을 바꿀 때 프롬프트도 함께 전환하세요.
