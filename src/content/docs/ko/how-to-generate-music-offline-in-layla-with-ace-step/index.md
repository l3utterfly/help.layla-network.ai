**Layla는 ACE-Step 1.5 음악 모델을 사용해 스타일, 멜로디, 편곡, 노래하는 가사까지 포함한 완성곡을 휴대폰에서만으로 생성할 수 있습니다. 아무것도 업로드되지 않고, 계정도 필요 없으며, 네트워크를 끈 상태에서도 작동합니다.**

![ACE-Step 로고.](./acestep.png)

이 문서에서는 Music Generation 미니 앱 설치, 모델 번들 내려받기, 프롬프트 작성, 그리고 속도와 품질을 좌우하는 매개변수 사용법을 다룹니다.

## ACE-Step이란?

ACE-Step은 ACE Studio와 StepFun이 개발한 음악 생성 모델입니다. 곡에 대한 텍스트 설명(장르, 분위기, 악기, 템포)과 선택적으로 가사를 받아 48kHz 스테레오의 완성된 오디오를 만들어 냅니다.

여러분이 사용해 봤을 온라인 AI 음악 생성 서비스와 달리, Layla의 ACE-Step은 기기의 CPU 또는 GPU에서 로컬로 실행됩니다. 대기열도, 크레딧 제도도, 트랙당 제한도 없습니다. 그 대신 데이터센터 GPU에서 몇 초면 끝날 작업이 휴대폰에서는 실제로 시간이 걸리고, 모델 파일도 큽니다.

Layla는 GGML 기반 구현인 [acestep.cpp](https://github.com/ServeurpersoCom/acestep.cpp)를 통해 ACE-Step을 실행합니다. Layla의 텍스트 모델이 [llama.cpp](https://github.com/ggerganov/llama.cpp) 위에서 동작하는 것과 같은 원리로, 모델을 휴대폰에 담길 크기로 양자화한 뒤 이미 가지고 있는 하드웨어에서 실행합니다.

## 준비물

- **안드로이드 또는 iOS용 Layla.** 음악 생성은 두 플랫폼에서 동일하게 작동합니다.
- **Layla 프리미엄 버전.** 모든 미니 앱에 필요합니다. Layla는 구독이 아니라 일회성 구매입니다.
- **약 5GB의 여유 저장 공간.** 모델 번들은 대략 4.2GB에서 5.3GB입니다.
- **6GB의 기기 RAM**(작은 양자화 기준), 큰 양자화에는 **8GB**.
- **첫 실행에는 시간이 걸립니다.** 세션의 첫 곡을 만들기 전에 모델을 메모리에 올려야 합니다.

## 1단계: Music Generation 미니 앱 활성화하기

음악 생성은 선택 기능이라 기본적으로 켜져 있지 않습니다. _내 앱_을 열고 오른쪽 위의 더하기 기호를 눌러 사용할 수 있는 기능을 살펴본 뒤 **Music Generation (Ace Step)** 을 활성화하세요.

미니 앱 시스템을 처음 사용한다면 [Layla에서 미니 앱을 활성화하거나 비활성화하는 방법](/ko/how-to-enable-disable-mini-apps-within-layla/)을 참고하세요.

활성화하면 앱 목록에 나타나며 **Create** 와 **Library** 두 개의 탭으로 열립니다.

## 2단계: 모델 번들 내려받기

Create 탭 상단의 모델 카드를 누르면 번들 선택 화면이 열립니다. 각 항목은 그 자체로 완결된 번들로, 가사와 멜로디를 쓰는 언어 모델, 오디오를 생성하는 디퓨전 트랜스포머, 텍스트 인코더, 그리고 결과를 소리로 바꾸는 디코더가 들어 있습니다. 고르는 것은 언제나 번들 하나뿐이며, 따로 맞춰야 할 파일은 없습니다.

번들은 두 가지 축으로 나뉩니다.

**변형** — 모델의 음악적 성격:

| 변형                    | 설명                                                              |
| ----------------------- | ----------------------------------------------------------------- |
| Turbo                   | 8스텝 고속 생성. 휴대폰에서 가장 무난한 기본값입니다.             |
| SFT-Turbo50             | turbo와 미세조정 모델의 병합. turbo의 속도에 조금 더 풍부한 결과. |
| Turbo Continuous        | 연속 재생이나 매끄러운 루프용으로 조정된 turbo.                   |
| Turbo Shift-1 / Shift-3 | 다른 샘플링 스케줄을 쓰는 turbo. 음색의 느낌이 달라집니다.        |

**양자화** — 크기와 품질의 절충으로, [텍스트 모델의 GGUF 양자화](/ko/what-are-gguf-models-what-are-model-quants/)와 같은 개념입니다:

| 양자화 | 참고                                 |
| ------ | ------------------------------------ |
| Q4_K_M | 가장 작고 품질이 가장 낮음. RAM 6GB. |
| Q5_K_M | 작고 균형 잡힘. RAM 6GB.             |
| Q6_K   | 더 크고 품질이 높음. RAM 8GB.        |
| Q8_0   | 가장 크고 거의 무손실. RAM 8GB.      |

고민된다면 **Turbo Q5_K_M** 으로 시작하세요.

_Download bundle_ 을 누르면 내려받기가 백그라운드에서 진행됩니다. 미니 앱을 벗어나도, 심지어 Layla를 종료해도 진행 상황이 사라지지 않습니다. 전송이 끝나면 Layla가 압축을 풀고 네 개의 모델 파일이 모두 도착했는지 확인합니다. 번들이 준비되면 카드에 _Installed_ 라고 표시됩니다.

더 이상 필요 없는 번들은 _Delete bundle_ 로 지우고 나중에 다시 내려받을 수 있습니다.

## 3단계: 음악 설명하기

**Style** 칸이 가장 중요한 입력란입니다. 연주자에게 설명하듯이 장르, 분위기, 악기 구성, 프로덕션, 템포를 적어 보세요.

약한 프롬프트:

> 팝송

더 나은 프롬프트:

> 몽환적인 신스팝, 따뜻한 아날로그 패드, 게이트 리버브 드럼, 숨결이 느껴지는 여성 보컬, 120bpm, 밝고 향수 어린

구체적일수록 좋습니다. 모델은 이 텍스트를 두 번 읽습니다. 한 번은 언어 모델이 구성과 가사를 짤 때, 또 한 번은 오디오 자체를 생성할 때입니다. 그래서 구체적인 악기, 프로덕션을 나타내는 형용사, 템포가 모두 결과를 뚜렷한 방향으로 이끕니다.

![Layla의 Music Generation 미니 앱 Create 탭. 모델 번들 카드, Style 칸, 섹션 태그가 들어간 Lyrics 칸이 보인다.](./lyrics.jpg)

## 4단계: 가사를 넣을지 말지

스타일 입력란 아래에 **Lyrics** 칸과 **Instrumental** 스위치가 있습니다.

- **가사 칸을 비워 두면** 모델이 스타일 설명을 바탕으로 직접 가사를 씁니다. 한 줄짜리 프롬프트에서 완성곡을 얻는 가장 빠른 방법입니다.
- **직접 가사를 쓰면** 모델이 그대로 노래합니다. 각 줄에 섹션 태그를 넣어 편곡을 잡아 줄 수 있습니다:

```
[verse]
Streetlights blink along the empty road
Radio static, half a song I know

[chorus]
Drive until the morning finds us
Nothing in the mirror behind us
```

`[intro]`, `[verse]`, `[pre-chorus]`, `[chorus]`, `[bridge]`, `[guitar solo]`, `[outro]` 같은 태그를 인식하며, `[bridge - saxophone and strings]` 처럼 태그에 설명을 덧붙일 수도 있습니다.

노래하는 언어는 여러분이 쓴 가사에서 감지되므로, 한국어나 일본어를 비롯해 모델이 지원하는 어떤 언어로 써도 그 언어로 불립니다.

- **Instrumental을 켜면** 보컬이 전혀 없는 트랙이 만들어집니다.

## 5단계: 길이와 시드

**Duration** 은 30초부터 3분까지의 사전 설정을 제공합니다. 곡이 길수록 생성 시간도 비례해 늘어나므로, 프롬프트를 다듬는 동안에는 30초가 알맞습니다.

**Seed** 는 무작위성을 조절합니다. 비워 두면 매번 다른 결과가 나오고, 숫자를 넣거나 주사위를 누르면 같은 결과를 재현할 수 있습니다. 시드와 프롬프트, 설정이 같으면 같은 곡이 나옵니다. 원하는 결과에 거의 다다라 프롬프트의 단어 하나만 바꾸고 싶을 때 유용합니다.

![Parameters 섹션. Use GPU 스위치, 길이 사전 설정, 시드 입력란, 그리고 Steps·Shift·Solver가 펼쳐진 Advanced 패널.](./duration.jpg)

## 트랙 생성하기

**Generate music** 을 누릅니다. 작업 전체에 걸쳐 하나의 진행 표시줄이 채워지며, 현재 단계가 라벨로 표시됩니다:

1. **Loading model** — 언어 모델을 메모리에 올립니다.
2. **Writing structure / Writing lyrics** — 템포, 조성, 박자, 그리고 직접 넣지 않았다면 가사.
3. **Composing melody** — 음악적 내용을 구성합니다.
4. **Generating music** — 오디오 자체를 한 단계씩 생성합니다.
5. **Decoding audio** — 결과를 파형으로 바꿉니다.

언제든지 **Stop** 을 누를 수 있습니다. 생성은 현재 단계가 끝난 뒤에 멈추므로 실제로 중단되기까지 잠시 기다려야 합니다. 작업이 끊기지 않도록 Layla가 그동안 화면을 켜 둡니다.

생성이 끝나면 파형이 있는 플레이어 카드가 나타납니다. 파형을 눌러 재생 위치를 옮기고, 재생 버튼으로 들어 보고, 내려받기 아이콘으로 파일을 저장하거나 공유하고, 휴지통 아이콘으로 삭제할 수 있습니다.

모든 트랙은 48kHz 스테레오 WAV로 미니 앱 전용 폴더에 기록되고, 생성에 쓰인 모델과 스텝 수, 시드와 함께 **Library** 탭에 표시됩니다. 자동으로 지워지지 않으니 필요 없는 것은 정리하세요. 이 품질의 WAV 파일은 용량이 금방 불어납니다.

## 고급 매개변수

더 세밀하게 조절하려면 Parameters 아래의 **Advanced** 를 펼치세요. 대부분은 손댈 일이 없고, 기본값이 함께 제공되는 모델에 알맞습니다.

**Steps 와 Shift** 는 기본적으로 비어 있으며, 이는 각 모델이 학습된 값을 그대로 쓴다는 뜻입니다. turbo 계열은 8스텝, base와 미세조정 모델은 50스텝입니다. 숫자를 넣으면 이를 덮어씁니다. 스텝이 많을수록 대체로 디테일이 늘고 시간도 늘어납니다.

**Solver** 는 샘플링 알고리즘을 고릅니다: Euler, SDE, DPM++ 3M, STORK-4. 기본값은 Euler입니다. 같은 스텝 수에서도 솔버를 바꾸면 결과의 질감이 달라지므로, 마음에 드는 프롬프트를 찾은 뒤 실험해 볼 만합니다.

**Guidance (CFG)** 는 오디오가 스타일 프롬프트를 얼마나 충실히 따르는지를 조절합니다. 효과가 있는 모델에서만 표시됩니다. turbo 모델은 가중치에 가이던스가 내장되어 있어, Layla가 1.0으로 고정하고 그 사실을 알려 결과가 과포화되지 않게 합니다.

**LM Guidance (CFG)** 는 가사와 멜로디 단계에 같은 역할을 하며 모든 모델에 적용됩니다. 기본값 1.0이 가장 빠른 설정입니다. 2.0 쪽으로 올리면 작곡이 프롬프트를 더 바짝 따르지만, 그 단계의 소요 시간이 대략 두 배가 됩니다.

**Use GPU** 는 오디오 생성을 기기의 GPU(iOS에서는 Metal, 안드로이드에서는 OpenCL)로 옮기며, 실패하면 CPU로 되돌아갑니다. 가사와 멜로디 단계는 언제나 CPU에서 실행됩니다. 이 작업은 연산보다 메모리에 묶여 있어 모바일 GPU에서 오히려 느리기 때문입니다. CPU 경로가 호환성의 기준이므로 GPU는 기본적으로 꺼져 있습니다. 더 빠른지는 각자의 기기에서 시험해 볼 가치가 있습니다.

**Flash attention** 은 품질을 약간 희생해 오디오 생성을 빠르게 합니다. 기본값은 꺼짐입니다.

**VAE tile size** 는 한 번에 디코딩하는 오디오의 양을 정합니다. 값을 낮추면 마지막 단계의 최대 메모리 사용량이 줄지만 속도가 조금 느려집니다. 생성은 끝나는데 RAM이 적은 기기에서 막바지에 앱이 종료되는 경우에 유용합니다.

![Advanced 패널의 아래쪽. LM Guidance, Flash attention 스위치, VAE tile size, 그리고 선택한 번들의 요약이 보인다.](./advanced.jpg)

맨 아래 패널은 실제로 무엇이 돌아가고 있는지 요약해 줍니다. 모델 계열, Qwen3-Embedding 텍스트 인코더, 함께 들어 있는 언어 모델의 크기, 그리고 출력 형식입니다.

## 직접 만든 모델 번들 가져오기

선택 화면에는 휴대폰에서 쓸 만한 turbo 계열이 들어 있습니다. 더 느린 base와 SFT 변형, 그 밖의 호환되는 번들은 직접 추가할 수 있습니다.

미니 앱 오른쪽 위의 _Import_ 를 누르고 `lm.gguf`, `dit.gguf`, `text_encoder.gguf`, `vae.gguf` 가 들어 있는 `.zip` 파일을 고르세요. Layla가 압축을 풀고, 중첩된 폴더를 평평하게 정리한 뒤, 네 파일이 모두 있는지 확인하고 목록에 추가합니다. 가져온 번들은 기본 제공 번들과 똑같이 동작하며 같은 방법으로 삭제할 수 있습니다.

## 더 좋은 결과를 얻으려면

- **30초로 반복해 보세요.** 짧은 클립에서 마음에 드는 프롬프트와 시드를 찾은 뒤, 같은 시드로 전체 길이를 다시 생성합니다.
- **장르뿐 아니라 프로덕션도 적으세요.** "따뜻한 바이닐 잡음", "정돈된 모던 믹스", "빈티지 아날로그의 온기" 는 모두 실제로 효과가 있습니다.
- **템포를 적으세요.** 스타일 프롬프트의 bpm 값이 리듬을 잡아 줍니다.
- **가사는 섹션으로 나누세요.** 태그 없는 문단만으로는 모델이 편곡할 구조를 잡을 수 없습니다.
- **한 번에 하나씩 바꾸세요.** 시드를 고정하면 프롬프트를 한 군데 고쳤을 때의 차이를 정확히 들을 수 있습니다.

## 자주 묻는 질문

### Layla의 AI 음악 생성은 오프라인에서 작동하나요?

네. 모델 번들을 한 번 내려받으면 생성은 전적으로 기기에서 이루어집니다. 비행기 모드로 두어도 그대로 작동합니다. 프롬프트와 가사는 기기를 벗어나지 않습니다.

### 휴대폰에서 한 곡을 생성하는 데 얼마나 걸리나요?

기기, 트랙 길이, 양자화, 스텝 수에 따라 크게 달라집니다. 30초짜리 turbo 생성을 해 보는 것이 자신의 기기 성능을 가늠하는 가장 빠른 방법입니다. 길이와 스텝 수를 늘리면 시간도 대체로 비례해 늘어납니다.

### 음악을 생성하려면 구독이 필요한가요?

아니요. 음악 생성은 Layla의 프리미엄 해제에 포함되며, 이는 일회성 구매입니다. 크레딧도, 트랙당 요금도, 월 요금도 없습니다.

### 생성한 음악을 상업적으로 사용할 수 있나요?

그것은 Layla가 아니라 ACE-Step 모델 가중치의 라이선스에 달려 있습니다. 상업적으로 사용하기 전에 모델 제작자가 공개한 약관을 확인하세요.

### 첫 번째 생성이 다음 것들보다 느린 이유는 무엇인가요?

첫 곡을 만들기 전에 모델을 메모리에 올려야 하기 때문입니다. 같은 세션의 이후 실행은 그 비용의 일부를 건너뜁니다.

### Layla는 어떤 오디오 형식으로 저장하나요?

48kHz 스테레오 WAV입니다. 각 트랙의 내려받기 아이콘으로 기기에 저장하거나 다른 앱으로 공유하세요.

---

음악 생성은 [이미지 생성](/ko/how-to-enable-image-generation-in-layla/), 오프라인 텍스트 대화와 더불어 Layla가 기기에서 직접 처리하는 기능입니다. 계정도, 업로드도, 연결도 필요 없습니다.
