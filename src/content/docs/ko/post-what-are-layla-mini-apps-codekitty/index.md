**Layla 미니 앱은 Layla 안에서 실행되는 독립형 웹 앱입니다. 브리지를 통해 API 키나 서버 없이도 휴대폰에 이미 있는 AI, 즉 로컬 모델, 이미지 생성, 음성, 캐릭터, 비공개 파일 저장 공간을 호출할 수 있습니다.**

![어두운 배경에 코드 기호가 있는 네온 사이버 고양이 로고.](./codekitty-logo.avif)

[CodeKitty](https://apps.layla-cloud.com/app/codekitty)는 다른 미니 앱을 만드는 미니 앱입니다. 코드 편집기, 실시간 미리보기, 프로젝트 라이브러리, 이미지 생성기, AI 코딩 도우미가 하나의 HTML 파일에 담겨 있습니다. 미니 앱 시스템의 거의 모든 부분을 활용하므로, 이 글에서는 CodeKitty를 통해 그 시스템의 작동 방식을 설명합니다.

## Layla 미니 앱이란?

미니 앱은 Layla가 WebView에서 실행하는 일반적인 웹 애플리케이션, 즉 HTML, CSS, JavaScript로 만든 앱입니다. 단순한 웹페이지를 넘어설 수 있게 하는 것은 호스트 브리지입니다.

일반적인 웹 앱에서 LLM을 사용하려면 API 키, 서버, 네트워크 연결이 필요합니다. 데이터도 외부로 전송합니다. Layla 미니 앱은 그렇지 않습니다. Layla 내부에서 실행되며, Layla가 기기에 이미 설치된 기능을 제공합니다. 여기에는 로컬 모델 추론, 이미지 생성, 텍스트 음성 변환, 캐릭터 목록, 앱별 비공개 파일 시스템이 포함됩니다.

이는 일반적인 구성을 뒤집습니다. AI는 앱이 외부에서 호출하는 서비스가 아니라 호스트가 제공하는 기능입니다. 인증할 외부 서비스가 없으므로 붙여 넣을 키, 설정할 endpoint, 만들 계정도 없습니다. 추론은 현재 불러온 [GGUF 모델](/ko/what-are-gguf-models-what-are-model-quants/)을 사용해 사용자의 하드웨어에서 실행됩니다.

미니 앱은 메타데이터용 `app.json`, 앱 본체인 `index.html`, 각종 에셋을 루트에 담은 ZIP 파일로 배포됩니다.

## CodeKitty란?

CodeKitty는 휴대폰에서 실행되며 설치 가능한 Layla 미니 앱을 만드는 IDE입니다.

프로젝트를 가상 파일 시스템, 즉 파일 이름을 키로 사용하는 JavaScript 객체로 다룹니다. 새 프로젝트는 `index.html`, `app.json`, `icon.jpg`, `bg.jpg`의 네 항목으로 시작합니다. 이 파일들은 디스크가 아니라 메모리에 있으므로, 기존 방식의 파일 시스템이 없어도 편집기에서 파일을 전환하고, 모델로 보내고, 미리보기에서 실행하고, ZIP으로 패키징할 수 있습니다.

인터페이스는 React를 사용하며, 구문 강조에는 Prism, 브라우저에서 JSX를 컴파일하는 데는 Babel, 패키징에는 JSZip, 도우미의 답변을 표시하는 데는 Marked를 사용합니다. 이 모든 것이 하나의 `index.html`에 들어 있습니다.

## 호스트가 API입니다

제작자가 가장 먼저 이해해야 할 점은 SDK가 클라우드 클라이언트가 아니라는 것입니다.

```js
const layla = new LaylaSDK();
```

설정은 이것이 전부입니다. 키도 기본 URL도 없습니다. `LaylaSDK`는 다음 호출을 직렬화합니다.

```js
window.ReactNativeWebView.postMessage(...);
```

Layla가 네이티브 환경에서 작업을 수행하고 WebView로 이벤트를 반환합니다. 미니 앱은 이를 통해 캐릭터, 스트리밍 채팅 완성, 이미지 생성, 음성, 비공개 파일, 네이티브 공유 기능에 접근할 수 있습니다.

실질적인 결과는 미니 앱을 작게 유지할 수 있다는 것입니다. 보통 백엔드, 인증, 미디어 서비스, 저장 계층이 필요한 기능도 호스트가 네 가지를 모두 갖추고 있으므로 메서드 호출 하나로 구현할 수 있습니다.

## 내 캐릭터가 도우미가 됩니다

CodeKitty는 각 캐릭터의 초상화를 가져와 검색 가능한 갤러리에 표시하고, 그중 하나를 코딩 친구로 선택할 수 있게 합니다. Character Card 데이터가 이름과 성격을 제공하며, CodeKitty는 이를 시스템 프롬프트에 넣습니다. 도우미는 캐릭터의 말투를 유지하면서 버그를 설명하거나 파일을 수정할 수 있습니다.

캐릭터 라이브러리는 모든 미니 앱이 읽을 수 있는 개인화 계층입니다. 피트니스 앱은 캐릭터를 코치로, 학습 도구는 과목별 튜터로, 스토리 게임은 등장인물로 활용할 수 있습니다. 캐릭터 목록은 이미 준비되어 있으며 SDK 호출 한 번으로 가져올 수 있습니다.

## 모델이 제안하고 앱이 적용합니다

변경을 요청할 때 CodeKitty는 사용자의 문장만 모델에 전달하지 않습니다. 코딩 친구의 성격, 현재 파일 이름과 전체 내용, 예상 출력 형식, 프로젝트 메모, 최근 채팅, 실시간 미리보기에서 수집한 오류, SDK 문서를 포함한 컨텍스트 패키지를 구성합니다. 그런 다음 응답 형식을 제한합니다.

소스 파일의 경우 모델은 전체 대체 파일이나 JSON 패치를 반환해야 합니다.

![검색 및 바꾸기 항목이 있는 JSON 패치를 보여 주는 코드 편집기.](./json-patch.avif)

`app.json`의 경우 모델은 전체 문서를 반환합니다. 이미지 에셋의 경우 코드 대신 시각적 프롬프트를 제안합니다.

이 분리가 핵심입니다. 모델은 제안하고, CodeKitty는 제안을 적용할지와 적용 방식을 결정합니다. 모델은 저장 공간이나 네이티브 호스트에 대한 쓰기 권한을 얻지 못하며, 적용된 모든 변경은 실행 취소용 스냅샷으로 남습니다. 언어 모델이 상태에 영향을 미치게 할 때는 코드가 직접 실행하는 동작이 아니라 코드가 검증할 수 있는 제안을 생성하게 해야 합니다.

휴대폰의 로컬 추론에는 시간이 걸리므로 생성 결과는 스트리밍됩니다.

![Layla 채팅 콘텐츠, 추론 이벤트, finalContent()를 처리하는 JavaScript 스트림 핸들러를 보여 주는 코드 편집기.](./streaming-events.avif)

추론 과정은 별도 채널로 도착해 접을 수 있는 패널에 표시됩니다. 스트림 핸들은 유지되므로 중지 버튼으로 생성을 취소할 수 있습니다. 미니 앱이 온디바이스 생성에 의존한다면 진행 상황을 제품의 일부로 다루세요. 텍스트를 스트리밍하고, 이미지 생성 단계를 표시하고, 항상 취소할 수 있게 해야 합니다.

## 미리보기가 브리지를 빌려 씁니다

실시간 미리보기는 CodeKitty에서 기술적으로 가장 흥미로운 기능입니다.

`index.html`은 샌드박스 iframe 안에서 실행됩니다. 실행하기 전에 CodeKitty는 두 가지를 삽입합니다. 첫째, 감싼 콘솔 메서드와 오류 처리기를 추가합니다. 처리되지 않은 예외가 콘솔 패널에 표시되고 다음 질문에서 모델의 컨텍스트에도 포함됩니다. 이로써 실행하고, 오류를 보고, 코딩 친구에게 질문하고, 패치를 적용한 뒤 다시 실행하는 짧은 순환이 만들어집니다.

둘째, `window.ReactNativeWebView` 프록시를 추가합니다. iframe 내부 앱이 SDK를 호출하면 프록시가 브리지 메시지를 CodeKitty에 전달합니다. CodeKitty는 이를 실제 Layla 호스트로 전달하고 네이티브 응답을 다시 iframe으로 보냅니다.

미리보기 앱은 CodeKitty의 Layla 연결을 빌려 씁니다. 파일 작업에는 프로젝트별 파일 이름 접두사가 붙으므로 테스트 앱이 `saveFile`을 호출해 CodeKitty 자체 라이브러리를 덮어쓸 수 없습니다. 미니 앱은 다른 웹 환경을 호스팅하면서 그 환경에 어떤 네이티브 기능을 제공할지 정확하게 중재할 수 있습니다.

## 아이콘, 배경, 내보내기

Layla 패키지에는 아이콘과 배경이 필요하므로 CodeKitty는 이미지 파일을 다른 파일과 동등한 프로젝트 탭으로 취급합니다. 프롬프트를 작성하거나 코딩 친구에게 요청한 다음 기기에서 이미지를 생성하세요.

```js
const imageSrc = await layla.images.generateImage();
```

결과는 canvas를 통해 중앙을 기준으로 잘립니다. 아이콘은 256×256, 배경은 854×480입니다. 내보내기 전까지 데이터 URI로 저장됩니다.

내보내기를 실행하면 루트에 `app.json`, `index.html`, 에셋을 담은 ZIP이 생성됩니다. 빌드는 두 종류입니다.

- **개발 빌드**는 모든 내용을 읽고 편집할 수 있는 상태로 유지합니다.
- **smashed 빌드**는 JSX를 컴파일하고, React를 인라인으로 포함하고, 글꼴을 데이터 URI로 삽입하고, 오프라인 사용을 위해 SDK 번들을 다시 작성하여 네트워크가 필요 없는 하나의 독립형 `index.html`을 만듭니다. 나중에 패키지를 CodeKitty로 다시 가져올 수 있도록 숨겨진 소스 사본도 포함합니다.

내보내기는 중간 확인 지점이지 끝이 아닙니다.

## 직접 미니 앱을 만들 때 참고할 점

CodeKitty의 좋은 아이디어를 활용하기 위해 IDE를 만들 필요는 없습니다.

호스트 기능 하나로 시작해 단순히 기능을 보여 주는 것이 아니라 실제 단계를 해결하도록 하세요. CodeKitty가 이미지를 생성하는 이유는 패키지에 아이콘이 필요하기 때문입니다. 로컬 생성을 고려해 설계하고, 스트리밍과 진행 상황 표시, 중지 기능을 제공하세요. 모델은 코드가 검증할 수 있는 계약 안에 두어야 합니다.

큰 데이터는 브리지를 통과시키지 마세요. CodeKitty는 라이브러리를 작은 인덱스와 프로젝트별 페이로드 파일로 나눕니다. 큰 base64 블록이 WebView 경계를 오가면 휴대폰이 느려지기 때문입니다. 피드백 순환도 만드세요. 미리보기 콘솔이 모델 컨텍스트가 되기 때문에 디버깅 순환이 제대로 작동합니다.

마지막으로 Layla 안에서 테스트하세요. SDK mock이 설치되지 않은 브라우저의 동작은 최종 기준이 아닙니다.

## 자주 묻는 질문

### Layla 미니 앱이란 무엇인가요?

Layla 안에서 실행되며 Layla SDK 브리지를 통해 기기의 AI, 즉 로컬 모델, 이미지 생성, 음성, 캐릭터, 비공개 저장 공간을 사용할 수 있는 독립형 웹 앱입니다. `app.json`, `index.html`, 에셋이 포함된 ZIP으로 배포됩니다.

### 만들려면 코딩을 할 줄 알아야 하나요?

생각보다 적은 지식으로도 가능합니다. CodeKitty 도우미가 코드를 작성하고 수정하며, 사용자는 자연어로 방향을 제시합니다. HTML과 JavaScript를 알면 더 빠르게 작업하고 모델의 실수를 직접 고칠 수 있지만, 설명하고 미리 보고 수정하는 순환은 해당 지식이 없어도 활용할 수 있습니다.

### CodeKitty는 오프라인에서 작동하나요?

AI는 오프라인에서 작동합니다. 코딩 도우미는 로컬 모델이며, 작성한 내용은 휴대폰 밖으로 나가지 않습니다. 현재 CodeKitty의 인터페이스 라이브러리는 처음 실행할 때 CDN에서 불러오므로 시작하려면 연결이 필요합니다. smashed 빌드로 내보낸 앱은 완전히 독립적이며 네트워크 연결 없이 실행됩니다.

### 내 코드는 어디로 가나요? 업로드되나요?

외부로 가지 않습니다. 프로젝트는 기기의 Layla 앱별 비공개 파일 저장 공간에 보관됩니다. 모델 추론도 기기에서 실행됩니다. 프로젝트를 보관하는 계정, 동기화, 서버는 없습니다.

### 만든 미니 앱을 공유할 수 있나요?

예. 내보내기를 실행하면 Layla 사용자 누구나 가져올 수 있는 ZIP이 생성됩니다. 원한다면 Layla의 Mini-app Manager를 통해 Layla Cloud에 업로드할 수 있습니다.

### 미니 앱은 무엇에 접근할 수 있나요?

캐릭터와 초상화, 로컬 모델을 사용하는 스트리밍 채팅 완성, 추론 엔진 선택, 이미지 생성, 설치된 TTS 음성, 해당 앱에만 허용된 비공개 파일 시스템에 접근할 수 있습니다. 다른 앱의 파일에는 접근할 수 없습니다.

### SDK 참조 문서가 있나요?

예. [`@layla-network/sdk` 저장소](https://github.com/l3utterfly/layla-sdk)를 참조하세요.

## 다음 미니 앱 만들기

CodeKitty는 고양이 테마의 코딩 친구가 있는 IDE이지만, 이 설명만으로는 더 흥미로운 사실을 충분히 전달하지 못합니다. 미니 앱은 완전한 로컬 워크플로가 될 수 있습니다. 이동 가능한 웹페이지 형태를 유지하면서 캐릭터, 모델, 이미지, 음성, 파일, 미리보기, 공유를 조율할 수 있습니다.

CodeKitty는 이 시스템으로 소프트웨어를 만듭니다. 같은 구조를 이용하면 설치된 음성으로 연습 문제를 읽어 주는 언어 튜터, 기기에 머물면서 관련된 과거 기록을 보여 주는 일기, 나만의 캐릭터 목록을 등장인물로 활용하는 스토리 스튜디오, 세션 사이에 메시지를 보내는 캠페인 도구도 만들 수 있습니다.

시작하기 위해 SDK 전체를 배울 필요는 없습니다. Layla 안에서 이루어지면 더 나아질 한순간을 찾고, 그 순간을 실현하는 가장 작은 것을 만들어 보세요.
