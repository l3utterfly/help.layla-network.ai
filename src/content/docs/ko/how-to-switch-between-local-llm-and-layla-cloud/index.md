다음과 같은 오류가 표시될 수 있습니다.

![Layla Cloud 앱을 통해 로그인해야 한다는 Layla Cloud 오류.](./layla-cloud-login-error.png)

Layla Cloud를 활성화한 경우 이 오류가 발생합니다.

**Layla Lite를 사용하는 경우**

기기에서 실행되는 로컬 LLM으로 돌아가려면 Layla 내에서 Layla Cloud 미니 앱을 제거하세요.

1. 큰 나비가 있는 메인 화면에서 *내 앱*으로 이동합니다.
2. 앱 영역의 오른쪽 위에 있는 빼기 아이콘을 누릅니다.
3. Layla Cloud 앱을 제거합니다.

**Layla(유료)를 사용하는 경우**

1. 추론 설정 앱으로 이동합니다.
2. 로컬 LLM 모델을 선택합니다.
