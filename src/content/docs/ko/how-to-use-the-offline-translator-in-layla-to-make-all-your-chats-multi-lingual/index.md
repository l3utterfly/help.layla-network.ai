Layla에는 **오프라인 번역기**라는 미니 앱이 포함되어 있습니다.

이 앱은 작은 언어 모델을 사용하여 인터넷 연결 없이 휴대전화에서 완전히 로컬로 언어 간 텍스트를 번역합니다.

실시간으로 대화를 번역할 수 있을 만큼 빠릅니다. 따라서 영어 LLM을 기본 채팅 AI로 사용하더라도 입력과 출력을 다른 언어로 자연스럽게 번역할 수 있습니다.

**오프라인 번역기 앱을 활성화하는 방법**

1. *미니 앱*으로 이동합니다.
2. `+`를 눌러 미니 앱을 추가합니다.
3. 앱 목록에서 *오프라인 번역기*를 검색합니다.
4. 활성화합니다.

![오프라인 번역기 미니 앱을 활성화하는 단계.](./enable-offline-translator.jpg)

**오프라인 번역기 사용 방법**

1. 상단의 언어 이름을 눌러 언어를 전환합니다.
2. 원하는 언어 조합을 검색합니다.
3. 번역 기능은 Google 번역과 다른 번역 앱처럼 작동합니다. 하단에서 *채팅 자동 번역*을 켭니다.
4. 일반적으로 AI 모델인 LLM은 영어를 사용합니다. 한국어 등의 입력을 AI가 사용할 영어로 자동 번역한 다음, AI의 출력을 다시 자신의 언어로 자동 번역하도록 설정합니다. _구름 다운로드 아이콘을 눌러 번역 모델을 다운로드했는지 확인하세요._

![채팅 양쪽 내용을 자동으로 번역하는 오프라인 번역기 설정.](./use-offline-translator.jpg)

이제 채팅이 자동으로 번역됩니다.
