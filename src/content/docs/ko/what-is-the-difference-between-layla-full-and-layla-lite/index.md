Layla에서는 기본 모델을 전환할 수 있습니다. 기본 모델은 Layla의 '두뇌'로, 모든 캐릭터, 장면, 역할극 및 기타 기능을 구동합니다.

기기의 성능에 따라([기기에서 지원되는 모델](https://www.layla-network.ai/contact) 참고) 여러 기본 모델 중에서 선택할 수 있습니다.

**Layla Lite**

- 휴대전화에 최소 4GB RAM이 필요합니다.
- 더 많은 사용자가 Layla를 이용할 수 있도록 주로 구형 기기를 대상으로 합니다.

**Layla Q2**

- 휴대전화에 4GB RAM이 필요합니다.
- 성능과 기능 사이의 균형을 맞춘 중간 모델입니다.

**Layla Full**

- 휴대전화에 최소 8GB RAM이 필요합니다. RAM은 휴대전화의 저장 공간과 다릅니다.
- Layla에서 가장 지능이 높은 버전입니다.
- 캐릭터 설정을 더 잘 유지합니다.
- 환각이 발생할 가능성이 더 낮습니다.
- 최근 2년 이내에 출시된 플래그십 기기에서만 실행됩니다.

**기본 모델을 전환하는 방법**

캐릭터 선택 화면에서 시작합니다.

1. 오른쪽 위의 톱니바퀴 아이콘을 눌러 _설정_ 페이지를 엽니다.
2. _위험 구역_ 섹션까지 아래로 스크롤합니다.
3. *기본 모델 전환*을 누릅니다.
4. 필요에 맞는 모델을 선택합니다.
