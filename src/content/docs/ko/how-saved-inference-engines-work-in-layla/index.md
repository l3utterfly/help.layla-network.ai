**저장된 추론 엔진은 Layla가 답변을 생성하는 방식을 지정하는 재사용 가능한 설정 모음입니다.** 모델 또는 모델 연결에 비전 모델, 프롬프트 템플릿, 사용자 페르소나, 샘플러 프리셋을 조합할 수 있습니다. 엔진을 직접 선택하거나 하나 이상의 캐릭터에 연결하여 채팅이 시작될 때 Layla가 적합한 구성을 사용하도록 할 수 있습니다.

하나의 구성이 모든 대화에 적합하지 않을 때 유용합니다. 일반 어시스턴트, 롤플레이 캐릭터, 이미지를 인식하는 캐릭터는 모두 같은 앱에서 작동하더라도 서로 다른 모델과 프롬프트가 필요할 수 있습니다.

## 추론 엔진은 AI 모델 이상의 구성입니다

모델은 텍스트를 생성하는 부분입니다. Layla에서 추론 엔진은 해당 모델을 실행하거나 호출하고 답변을 준비하는 데 사용되는 더 넓은 구성을 뜻합니다.

예를 들어, 저장된 두 엔진에서 같은 로컬 GGUF 모델을 사용하면서 프롬프트 템플릿, 페르소나 또는 생성 설정을 다르게 지정할 수 있습니다. 또는 한 엔진은 휴대전화에 저장된 모델을 사용하고, 다른 엔진은 Layla Server, Layla Cloud, OpenAI 호환 API 또는 Claude API에 연결할 수 있습니다.

**내 모델**은 Layla에서 사용할 수 있는 모델과 연결의 모음입니다. **저장된 엔진**은 특정 설정 조합에 이름을 붙여 나중에 다시 사용할 수 있는 구성으로 만듭니다.

사용할 모델이나 연결을 아직 추가하지 않았다면 [Layla에 사용자 지정 AI 모델을 추가하는 방법](/ko/how-to-add-custom-models-to-layla/)을 참고하세요.

## 저장된 추론 엔진에 포함되는 항목

현재 구성을 엔진으로 저장하면 Layla는 다음 선택 항목을 함께 보관합니다.

- **모델 및 추론 소스:** 로컬 모델, Layla Server, Layla Cloud, OpenAI 호환 서비스 또는 Claude 호환 서비스.
- **비전 모델:** 언어 모델이 이미지를 이해해야 할 때 사용하는 선택된 비전 구성 요소.
- **프롬프트 템플릿:** 캐릭터 지침, 컨텍스트, 사용자 메시지, 답변을 모델에 전달하기 위해 배열하는 형식.
- **페르소나:** 캐릭터에게 제시되는 사용자의 정체성과 설명.
- **샘플러 프리셋:** 엔진의 이름을 지정하거나 편집할 때 선택하는, 저장된 생성 제어 설정.
- **캐릭터 연결:** 이 엔진을 자동으로 사용하도록 지정한 캐릭터.

엔진에는 모델 파일 자체가 포함되지 않습니다. 따라서 엔진을 저장해도 로컬 GGUF 모델의 사본이 추가로 생성되지 않습니다. 엔진이 작동하려면 원본 모델 또는 구성된 연결을 계속 사용할 수 있어야 합니다.

이미지 생성 모델은 별도로 설정합니다. 캐릭터 음성, Agents, LoreBook, 캐릭터 지침, 채팅 기록도 저장된 추론 엔진과 별개입니다.

## 저장된 추론 엔진을 만드는 방법

Layla의 **설정** 페이지에서 **추론 설정**을 열거나 **추론 설정** 미니 앱을 직접 여세요.

1. **내 모델**에서 사용할 모델 또는 연결을 선택하세요.
2. 해당 모델에 적합한 프롬프트 템플릿을 선택하세요.
3. 구성에서 이미지를 처리해야 한다면 비전 모델을 선택하세요.
4. 이 구성에서 사용할 사용자 페르소나를 선택하세요.
5. **저장된 엔진**에서 **현재 설정을 사용자 지정 엔진으로 저장**을 누르세요.

Layla가 먼저 현재 모델, 비전, 프롬프트, 페르소나의 요약을 표시합니다. 계속하기 전에 내용을 확인하세요. 여기에 표시된 설정이 재사용 가능한 엔진으로 저장됩니다. 별도 구성을 추가하려면 **새 엔진 만들기**를 누르세요. 저장된 엔진이 이미 있다면 **기존 엔진 교체**에서 하나를 선택하여 현재 구성으로 업데이트할 수도 있습니다.

![선택한 Layla Cloud 모델, 비전 설정, Cloud 프롬프트, User 페르소나를 요약해서 보여 주는 엔진으로 저장 창.](./new.jpg)

다음 창에서는 Layla가 엔진을 식별하고 사용하는 방식을 지정합니다.

6. 알아보기 쉬운 엔진 이름을 입력하세요.
7. 저장된 샘플러 프리셋을 선택하거나 Layla의 일반 생성 설정을 사용하려면 **글로벌**을 그대로 두세요.
8. **캐릭터에 연결**에서 이 엔진으로 자동 전환할 캐릭터를 모두 선택하세요.
9. **변경 사항 저장**을 누르세요.

![엔진 이름, 글로벌 샘플러 프리셋, 연결할 수 있는 여러 캐릭터가 표시된 추론 엔진 편집 창.](./edit.jpg)

‘로컬 일반 채팅’, ‘비전 어시스턴트’, ‘롤플레이 — 창작’과 같은 이름을 사용하면 엔진 목록을 더 쉽게 확인할 수 있습니다. 캐릭터에 여러 엔진을 연결하면 Layla가 선택 창에 엔진 이름을 표시하므로 명확한 이름이 특히 중요합니다.

모델에 맞는 프롬프트 형식을 선택하는 방법은 [Layla에서 모델용 사용자 지정 프롬프트 템플릿을 설정하는 방법](/ko/how-to-set-up-custom-prompt-templates-for-models/)을 참고하세요.

## Layla가 채팅에 사용할 엔진을 선택하는 방법

채팅이 시작되면 Layla는 캐릭터에 연결된 저장 엔진이 있는지 확인합니다.

### 캐릭터에 연결된 엔진이 없는 경우

Layla는 **추론 설정**의 현재 일반 구성을 사용합니다. 전용 구성이 필요하지 않은 캐릭터에 적용되는 일반적인 대체 설정입니다.

일반 구성을 바꾸려면 **저장된 엔진**에서 현재 엔진 카드를 열고 다른 저장 엔진을 선택하세요. 선택한 엔진의 모델, 비전, 프롬프트, 페르소나가 현재 구성으로 로드됩니다.

### 캐릭터에 엔진 하나가 연결된 경우

Layla는 해당 엔진을 자동으로 사용합니다. 일반 구성보다 우선하므로 매번 채팅을 시작하기 전에 설정을 전환하지 않아도 캐릭터가 지정된 모델과 프롬프트를 일관되게 사용할 수 있습니다.

### 캐릭터에 여러 엔진이 연결된 경우

일반 캐릭터 채팅에서는 대화를 로드하기 전에 사용할 엔진을 선택하라는 메시지가 표시됩니다. 따라서 한 캐릭터에 짧은 채팅용 빠른 로컬 모델과 긴 롤플레이용 대형 모델처럼 여러 유효한 구성을 지정할 수 있습니다.

선택 창에는 각 엔진의 이름과 모델 소스가 표시됩니다. 해당 채팅에서 사용할 구성을 누르면 Layla가 선택한 엔진을 로드합니다.

![같은 캐릭터에 연결된 두 추론 엔진 중 하나를 선택하라고 안내하는 Layla 캐릭터 채팅.](./select.jpg)

## 열린 채팅에서 사용 중인 엔진을 확인하는 방법

열린 대화 상단의 채팅 제목을 눌러 **채팅 정보**를 확인하세요. **추론 엔진**을 펼치면 선택된 엔진, 프롬프트 형식, 시스템 프롬프트 상태, 페르소나를 볼 수 있습니다. 같은 창에서 샘플러 설정과 기타 채팅 기능을 별도로 보여 주므로 추론 엔진과 이미지 생성, 장기 기억, Agents의 차이를 확인하는 데 도움이 됩니다.

![My engine 프리셋, Cloud 프롬프트 형식, 활성화된 시스템 프롬프트, User 페르소나가 표시된 채팅 정보 창.](./info.jpg)

## 그룹 롤플레이에서 연결된 엔진이 작동하는 방식

그룹 롤플레이에서는 참가자마다 다른 엔진을 연결할 수 있습니다. Layla는 현재 말할 차례인 캐릭터와 연결된 엔진을 확인하고 필요할 때 모델 구성을 변경합니다.

예를 들어 한 참가자에게는 롤플레이 중심 로컬 모델을 지정하고, 다른 참가자에게는 다른 모델이나 프롬프트 형식을 지정할 수 있습니다. 연속해서 말하는 캐릭터들이 같은 엔진을 사용하면 Layla는 모델을 다시 로드하지 않고 준비된 상태로 유지할 수 있습니다. 서로 다른 로컬 모델을 전환하려면 시간이 걸리고 많은 메모리가 필요할 수 있으므로, 기기 리소스가 제한적이라면 여러 참가자가 같은 엔진을 공유하는 편이 일반적으로 더 원활합니다.

## 엔진에서 샘플러 프리셋 사용하기

샘플러 설정은 모델이 다음 단어를 선택하는 방식에 영향을 줍니다. 예측 가능성, 다양성, 답변 길이, 반복 정도 등이 달라질 수 있습니다.

저장된 엔진을 편집할 때 저장된 샘플러 프리셋 중 하나를 연결하거나 **글로벌**을 그대로 둘 수 있습니다. 자체 프리셋이 있고 캐릭터에 연결된 엔진은 모델이 시작될 때 해당 프리셋을 사용합니다. **글로벌**은 Layla 고급 설정의 현재 생성 설정을 사용합니다.

샘플러 프리셋은 특정 캐릭터나 모델에 다른 생성 동작이 필요할 때 유용합니다. 예를 들어 창작 중심 롤플레이 구성에는 간결한 어시스턴트와 다른 프리셋을 사용할 수 있습니다. 하지만 호환되지 않는 프롬프트 템플릿을 고치거나 너무 큰 모델을 메모리에 맞게 만들지는 않습니다. 이러한 요소는 구성의 별도 부분입니다.

## 엔진 편집, 교체 및 삭제하기

**저장된 엔진**에서 현재 엔진 카드를 열어 저장 목록을 확인하세요. 각 카드에는 엔진 이름, 모델 소스, 프롬프트, 페르소나, 연결된 캐릭터가 표시됩니다. 엔진에 비전 또는 샘플러 프리셋이 포함되어 있으면 추가 레이블도 표시됩니다.

상단의 캐릭터 필터를 사용하면 특정 캐릭터에 연결된 엔진만 표시할 수 있습니다. 엔진 카드를 누르면 해당 구성이 현재 설정이 되고, 연필 아이콘을 누르면 편집할 수 있습니다.

![캐릭터 필터와 함께 모델 소스, 프롬프트, 페르소나, 연결된 캐릭터가 표시된 두 개의 저장된 추론 엔진 목록.](./list.jpg)

편집 화면에서 엔진 이름 변경, 샘플러 프리셋 변경, 캐릭터 연결 업데이트 또는 삭제를 할 수 있습니다. 모델, 비전, 프롬프트, 페르소나 선택을 한꺼번에 업데이트하려면 먼저 기본 **추론 설정** 페이지에서 새 조합을 준비하세요. 그런 다음 **현재 설정을 사용자 지정 엔진으로 저장**을 누르고 기존 엔진을 교체하세요.

엔진을 삭제하면 재사용 가능한 구성과 캐릭터 연결이 제거됩니다. 원본 로컬 모델, 캐릭터, 페르소나, 프롬프트 템플릿 또는 채팅 기록은 삭제되지 않습니다.

## 개인정보 보호 및 네트워크 사용

추론 엔진을 저장하는 것만으로 오프라인 작동 여부가 정해지지는 않습니다. 엔진에 포함된 모델 소스에 따라 달라집니다.

로컬 모델과 로컬 비전 모델은 기기에서 완전히 실행할 수 있습니다. Layla Server는 사용자의 컴퓨터에 연결하며, Layla Cloud와 타사 API는 구성된 서비스로 요청을 보냅니다. 따라서 엔진을 전환하면 추론이 이루어지는 위치와 적용되는 개인정보 보호 조건도 달라질 수 있습니다.

## 자주 묻는 질문

### 저장된 추론 엔진은 모델과 같은 것인가요?

아니요. 모델은 엔진의 한 부분입니다. 저장된 엔진은 연결된 비전, 프롬프트, 페르소나, 샘플러, 캐릭터 연결 설정도 기억합니다.

### 엔진을 저장하면 로컬 모델이 복제되나요?

아니요. 엔진은 Layla에서 이미 사용할 수 있는 모델을 참조합니다. GGUF 또는 LiteRT 파일의 사본을 추가로 만들지 않습니다.

### 엔진 하나를 여러 캐릭터에 연결할 수 있나요?

예. 엔진을 만들거나 편집할 때 해당 엔진을 사용할 캐릭터를 모두 선택하세요.

### 같은 캐릭터에 여러 엔진을 연결하면 어떻게 되나요?

해당 캐릭터와 일반 채팅을 열면 Layla가 연결된 엔진 중 사용할 엔진을 선택하라고 안내합니다.

### 연결된 엔진이 일반 추론 설정보다 우선하나요?

예. Layla가 활성 캐릭터에 연결된 엔진을 찾으면 해당 엔진이 우선합니다. 일치하는 연결이 없으면 **추론 설정**에서 선택한 일반 구성을 사용합니다.

### 저장된 엔진에 이미지 생성도 포함되나요?

아니요. 이미지 생성 모델과 설정은 언어 모델 추론 엔진과 별도로 관리됩니다.

### 저장된 엔진에서 사용하는 모델을 삭제하면 어떻게 되나요?

엔진에서 작동하는 모델을 더 이상 로드할 수 없습니다. 다른 모델을 선택하고 저장된 엔진을 교체하거나, 누락된 모델 또는 연결을 복원하세요.

저장된 추론 엔진을 사용하면 모델 파일을 복제하지 않고 여러 모델 구성을 정리할 수 있습니다. 로컬 엔진은 기기의 오프라인 구성으로 유지되며, PC 또는 온라인 서비스를 의도적으로 사용하려는 경우에는 원격 엔진을 사용할 수 있습니다.
