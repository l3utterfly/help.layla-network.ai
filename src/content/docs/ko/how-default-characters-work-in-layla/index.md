**기본 캐릭터는 사용자가 직접 캐릭터를 선택하지 않고 상호작용을 시작할 때 Layla가 선택하는 캐릭터입니다.** 시작 화면에 표시되고, Layla가 채팅으로 바로 시작될 때 열리며, 별도 캐릭터가 지정되지 않은 빠른 작업을 처리하고, Layla를 휴대전화 어시스턴트로 사용할 때의 캐릭터가 될 수 있습니다.

Layla는 처음에 내장 캐릭터 Layla를 기본으로 사용합니다. 언제든지 프리셋, 가져온 캐릭터 또는 사용자 지정 캐릭터로 바꿀 수 있습니다.

## 기본 캐릭터 설정하기

사용할 캐릭터와의 일반 채팅 안에서 설정할 수 있습니다.

1. **개성 선택**을 열고 캐릭터를 선택합니다.
2. 해당 캐릭터와 새 채팅을 시작하거나 기존 채팅을 다시 엽니다.
3. 채팅 오른쪽 위의 **점 세 개**를 누릅니다.
4. **기본값으로 설정**을 누릅니다.

아래 예시에서는 Annie와의 채팅을 열고 Annie를 기본 캐릭터로 설정했습니다.

![Annie의 채팅 설정에서 기본값으로 설정 옆에 금색 메달 아이콘이 표시된 화면.](./setasdefault.jpg)

열려 있는 캐릭터가 이미 기본 캐릭터라면 **기본값으로 설정** 옆의 메달 아이콘이 금색으로 표시됩니다. 기본 캐릭터 목록은 따로 없으며 한 번에 한 캐릭터만 기본값으로 지정할 수 있습니다. 변경하려면 다른 캐릭터와의 채팅을 열고 같은 단계를 반복하세요.

아직 캐릭터를 만들지 않았다면 [Layla에서 사용자 지정 AI 캐릭터를 만드는 방법](/how-do-i-create-custom-characters/)을 읽거나 [Personalities Hub에서 캐릭터를 다운로드](/personality-hub-ai-characters/)하세요.

## 기본값 설정 후 달라지는 점

기본 캐릭터를 설정하면 앱의 다른 기능에서 캐릭터가 필요하지만 특정 캐릭터를 지정하지 않았을 때 누구를 사용할지 Layla가 알 수 있습니다. 새 상호작용을 준비할 때 해당 캐릭터의 정체성, 성격, 외모 및 구성된 채팅 기능이 사용됩니다.

이미 열려 있는 대화의 캐릭터가 바뀌거나 저장된 메시지 및 캐릭터 자체가 수정되지는 않습니다. 채팅 기록도 병합되지 않습니다. **개성 선택**에서 계속 원하는 다른 캐릭터를 자유롭게 선택할 수 있습니다.

## 시작 화면

**환영** 시작 화면을 사용 중이라면 화면으로 돌아가는 즉시 결과를 볼 수 있습니다. Layla는 기본 캐릭터의 이름과 기본 이미지를 표시하며, 큰 캐릭터 이미지를 누르면 해당 캐릭터와 채팅을 시작합니다. 사용자 지정 배경화면을 선택하지 않았다면 캐릭터의 배경도 사용됩니다.

아래에서는 내장 Layla 캐릭터 대신 Annie가 시작 화면에 표시됩니다.

![채팅 시작 컨트롤 위에 Annie의 이름과 캐릭터 이미지가 표시된 Layla 시작 화면.](./welcome.jpg)

기본 미니 앱은 별도의 설정입니다. 시작 화면의 큰 아이콘을 대체할 미니 앱을 선택한 경우 이 아이콘을 누르면 기본 캐릭터 대신 미니 앱이 열립니다. 다른 곳에서는 캐릭터가 계속 기본값으로 사용됩니다. 시작 화면 아이콘으로 캐릭터를 다시 열려면 **Wallpaper & UI** 미니 앱에서 기본 미니 앱을 제거하세요.

## Layla를 채팅으로 바로 열기

Layla가 캐릭터 채팅으로 바로 열리게 하려면 **설정** > **UI 설정** > **시작 화면**으로 이동하여 **채팅**을 선택하세요. 이 채팅에는 기본 캐릭터가 사용됩니다.

이 설정은 **환영**을 시작 화면으로 사용하는 것과 별개입니다. **환영**에서는 먼저 캐릭터가 표시되고 이를 눌러 채팅을 시작합니다. **채팅**에서는 Layla가 채팅 화면으로 바로 이동합니다.

## Layla를 휴대전화 어시스턴트로 사용하기

Layla를 휴대전화의 기본 어시스턴트로 구성했다면 어시스턴트를 열 때 Layla의 기본 캐릭터가 사용됩니다. 입력란은 **[캐릭터 이름]에게 묻기...**로 바뀌며 해당 세션에는 캐릭터의 성격과 구성된 기능이 적용됩니다. 이 예시에서는 Annie를 시작 화면에 표시한 것과 같은 설정으로 어시스턴트 입력란도 **Ask Annie...**로 변경되었습니다.

![Android 홈 화면 위에 휴대전화 어시스턴트로 열린 Layla와 Ask Annie 입력란.](./assistant.jpg)

Layla 안에서 캐릭터를 기본값으로 설정하는 것만으로 Google Gemini나 다른 시스템 어시스턴트가 대체되지는 않습니다. 이는 휴대전화의 별도 설정입니다. Android 설정 방법은 [Google Gemini를 Layla로 바꾸어 휴대전화의 기본 어시스턴트로 사용하는 방법](/how-to-replace-google-gemini-with-layla-as-your-phone-s-default-assistant/)을 참조하세요.

## 빠른 작업과 공유한 텍스트

빠른 작업에는 특정 캐릭터를 지정할 수 있습니다. 작업에 별도 캐릭터가 없으면 Layla가 기본 캐릭터를 사용합니다. Layla로 공유한 텍스트를 요약하거나 설명하고, 알림을 설정하거나, 웹을 검색하는 표준 작업도 여기에 포함됩니다.

빠른 작업의 캐릭터를 선택할 때도 기본 캐릭터가 가장 먼저 표시됩니다. 개별 작업에 다른 캐릭터를 지정하면 해당 작업에 한해 기본값보다 우선합니다.

지원되는 iOS 단축어에서도 다른 캐릭터를 지정하지 않고 Layla로 보낸 텍스트는 기본 캐릭터로 열립니다.

## 장기 기억 연동

다른 앱이나 자동화가 Layla의 **기억하기** 작업으로 텍스트를 보내면 해당 기억이 기본 캐릭터와 연결됩니다. 장기 기억은 캐릭터별로 정리되므로 이 점이 중요합니다. 나중에 기본 캐릭터를 바꿔도 이미 저장된 기억은 이동하지 않습니다.

이는 열려 있는 채팅에서 메시지를 직접 선택하고 **장기 기억에 추가**를 사용하는 것과 별개입니다. 이 경우 메시지는 열려 있는 채팅의 캐릭터에 속합니다.

## 별도로 유지되는 설정

이름이 비슷한 다음 옵션에는 기본 캐릭터가 자동으로 적용되지 않습니다.

- **기존 채팅:** 저장된 대화를 다시 열면 현재 기본 캐릭터로 교체되지 않고 해당 대화의 캐릭터가 사용됩니다.
- **캐릭터가 지정된 빠른 작업:** 작업에 지정된 캐릭터가 우선합니다.
- **기본 미니 앱:** 시작 화면의 큰 아이콘에서 열리는 대상을 바꿀 수 있지만 다른 곳에서 사용되는 캐릭터는 바꾸지 않습니다.
- **컴패니언 모드:** 자체 캐릭터 선택 기능이 있습니다. 기본 캐릭터를 변경해도 활성 컴패니언은 바뀌지 않습니다.
- **롤플레이 시나리오 및 그룹 채팅:** 캐릭터는 롤플레이 미니 앱 안에서 선택되며 기본 캐릭터 설정을 물려받지 않습니다.

## 자주 묻는 질문

### 기본 캐릭터를 여러 명 설정할 수 있나요?

아니요. Layla는 한 번에 한 명의 기본 캐릭터만 저장합니다. 다른 캐릭터를 기본값으로 설정하면 이전 선택이 교체됩니다.

### 어떤 캐릭터가 기본값인지 어떻게 확인하나요?

해당 캐릭터와의 채팅을 열고 점 세 개를 누른 다음 **기본값으로 설정**을 확인하세요. 현재 기본 캐릭터라면 메달이 금색으로 표시됩니다.

### 기본 캐릭터를 바꾸면 새 채팅이 시작되나요?

아니요. **기본값으로 설정**을 누르면 환경설정만 저장됩니다. 이후 시작 화면에서 캐릭터를 열거나, Layla를 **채팅**으로 시작하거나, 해당하는 빠른 작업을 사용하거나, Layla를 휴대전화 어시스턴트로 열 때 새 채팅이 시작됩니다.

### 기존 채팅 기록이 변경되나요?

아니요. 기존 기록과 메시지는 그대로 유지됩니다. Layla가 새 상호작용에 사용할 캐릭터를 선택해야 할 때 기본값이 사용됩니다.

### 시작 화면에서 캐릭터를 누르면 미니 앱이 열리는 이유는 무엇인가요?

기본 미니 앱을 선택했을 가능성이 큽니다. **Wallpaper & UI**를 열고 기본 미니 앱 설정을 찾은 다음 **기본 앱 제거**를 선택하세요. 그러면 시작 화면 아이콘이 다시 기본 캐릭터를 사용합니다.

### 기본 캐릭터가 컴패니언 캐릭터도 되나요?

아니요. 컴패니언 모드의 캐릭터는 별도로 선택하세요.

채팅, 빠른 작업 및 휴대전화 어시스턴트 인터페이스에서 같은 캐릭터를 자주 사용한다면 기본 캐릭터 설정이 유용합니다. 다른 대화에서 선택할 수 있는 캐릭터를 제한하지 않으면서 이러한 진입점에서 일관된 캐릭터를 사용할 수 있습니다.
