Layla organises her features into "mini-apps". These are self-contained modules you can add to Layla to customise your experience.

You can add or remove them as you see fit; mix and match to make Layla yours!

**Note: The one-time purchase unlocks all mini-apps forever. You can remove and add them again in the future without an additional purchase.**

You can browse and add mini-apps by:

1. Tapping the second option below the big blue butterfly icon on the first screen. The button should say **Add mini-apps**.
2. Using the grid icon at the top-right corner during character selection. It should be next to the gear icon.
