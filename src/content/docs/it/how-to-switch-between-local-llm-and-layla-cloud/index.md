A volte può comparire questo errore:

![Errore Layla Cloud che richiede di accedere tramite l'app Layla Cloud.](./layla-cloud-login-error.png)

Questo accade se hai attivato Layla Cloud.

**Se utilizzi Layla Lite**

Per tornare agli LLM locali eseguiti sul dispositivo, disinstalla la mini-app Layla Cloud all'interno di Layla:

1. Dalla schermata principale con la grande farfalla, apri _Le mie app_.
2. Tocca l'icona meno nell'angolo in alto a destra dell'area delle app.
3. Rimuovi l'app Layla Cloud.

**Se utilizzi Layla (a pagamento)**

1. Apri l'app Impostazioni di inferenza.
2. Scegli un modello LLM locale.
