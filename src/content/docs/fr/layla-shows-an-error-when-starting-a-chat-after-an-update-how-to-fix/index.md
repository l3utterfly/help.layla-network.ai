Il arrive qu'une erreur comme celle-ci apparaisse pendant le chargement du modèle ou après une mise à jour :

![Erreur REPL affichée pendant le chargement d'un modèle Layla.](./model-load-error.png)

Ces erreurs peuvent généralement être corrigées en ouvrant la page _Paramètres_, en faisant défiler vers le bas, puis en sélectionnant _Vider le cache_.

Il est très rare qu'une erreur nécessite de télécharger à nouveau les modèles ou l'application. Le vidage du cache permet de réinitialiser l'application dans un état propre.

Remarque : après avoir vidé le cache, le premier chargement des personnages sera lent.
