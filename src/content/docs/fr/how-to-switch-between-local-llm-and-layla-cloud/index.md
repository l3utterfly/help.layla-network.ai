Il peut arriver que cette erreur s'affiche :

![Erreur Layla Cloud indiquant que vous devez vous connecter depuis l'application Layla Cloud.](./layla-cloud-login-error.png)

Elle se produit lorsque Layla Cloud est activé.

**Si vous utilisez Layla Lite**

Pour revenir aux LLM locaux exécutés sur votre appareil, désinstallez la mini-application Layla Cloud dans Layla :

1. Depuis l'écran principal avec le grand papillon, ouvrez _Mes applications_.
2. Appuyez sur l'icône moins dans le coin supérieur droit de la zone des applications.
3. Supprimez l'application Layla Cloud.

**Si vous utilisez Layla (version payante)**

1. Ouvrez l'application Paramètres d'inférence.
2. Choisissez un modèle LLM local.
