Layla organise ses fonctionnalités sous forme de « mini-applications ». Il s'agit de modules autonomes que vous pouvez ajouter à Layla afin de personnaliser votre expérience.

Vous pouvez les ajouter ou les supprimer selon vos besoins et les combiner pour adapter Layla à votre usage.

**Remarque : l'achat unique déverrouille définitivement toutes les mini-applications. Vous pourrez les supprimer et les ajouter à nouveau sans achat supplémentaire.**

Vous pouvez parcourir et ajouter des mini-applications de deux façons :

1. Appuyez sur la deuxième option située sous la grande icône de papillon bleu sur le premier écran. Le bouton doit indiquer **Ajouter des mini-applications**.
2. Utilisez l'icône en forme de grille dans le coin supérieur droit de l'écran de sélection des personnages. Elle se trouve à côté de l'icône d'engrenage.
