Layla comprend de nombreuses fonctionnalités qui ne sont pas activées par défaut. Ces fonctionnalités sont facultatives, mais restent disponibles si vous en avez besoin.

<video controls playsinline src="/assets/articles/how-to-enable-disable-mini-apps-within-layla/browse-mini-apps.mp4"></video>

Dans Layla, ces fonctionnalités sont organisées sous forme de **mini-applications**. Les mini-applications ressemblent aux applications habituelles de votre téléphone, mais elles sont intégrées à Layla et conçues pour fonctionner avec ses fonctionnalités.

Elles permettent, entre autres, de configurer des personnages ou d'activer la génération d'images.

Pour afficher la liste des applications actuellement installées, appuyez sur le bouton _Mes applications_ dans l'un des écrans ci-dessous :

![Bouton Mes applications dans Layla.](./my-apps-button.jpg)

La liste des applications actuellement activées s'affiche :

![Écran Mes applications affichant les mini-applications Layla activées.](./my-apps-screen.jpg)

Le signe plus ou moins dans le coin supérieur droit permet de parcourir toutes les fonctionnalités proposées par Layla.

_Remarque : toutes les mini-applications nécessitent la version premium de Layla. Vous pouvez acheter cette version sur Google Play ou depuis l'écran d'achat de la version APK directe. Layla propose un achat unique qui déverrouille toutes les fonctionnalités ; aucun abonnement mensuel n'est requis._
