Layla vous permet de changer de modèle de base. Le modèle de base est le « cerveau » de Layla : il fait fonctionner tous les personnages, scènes, jeux de rôle et autres fonctionnalités.

Selon les capacités de votre appareil — consultez [les modèles compatibles avec votre appareil](https://www.layla-network.ai/contact) — vous pouvez choisir parmi plusieurs modèles de base :

**Layla Lite**

- Nécessite au moins 4 Go de RAM sur le téléphone.
- Principalement destiné aux appareils plus anciens afin de rendre Layla accessible à davantage d'utilisateurs.

**Layla Q2**

- Nécessite 4 Go de RAM sur le téléphone.
- Un modèle intermédiaire qui offre un équilibre entre performances et capacités.

**Layla Full**

- Nécessite au moins 8 Go de RAM sur le téléphone. La RAM est différente de l'espace de stockage du téléphone.
- La version la plus intelligente de Layla.
- Respecte mieux le personnage.
- Est moins sujette aux hallucinations.
- Fonctionne uniquement sur les appareils haut de gamme commercialisés au cours des deux dernières années.

**Comment changer de modèle de base**

Depuis l'écran de sélection des personnages :

1. Appuyez sur l'icône d'engrenage dans le coin supérieur droit pour ouvrir la page _Paramètres_.
2. Faites défiler jusqu'à la section _Zone dangereuse_.
3. Appuyez sur _Changer de modèle de base_.
4. Choisissez le modèle adapté à vos besoins.
