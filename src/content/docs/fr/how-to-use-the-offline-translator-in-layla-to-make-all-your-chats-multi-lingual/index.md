Layla propose une mini-application appelée **Traducteur hors ligne**.

Elle utilise un petit modèle de langage qui traduit les textes entre différentes langues entièrement en local sur votre téléphone, sans aucune connexion Internet.

Elle est suffisamment rapide pour traduire les conversations en temps réel. Ainsi, même si vous utilisez un LLM anglais comme IA principale, vous pouvez traduire de manière fluide vos messages et les réponses dans d'autres langues.

**Comment activer l'application Traducteur hors ligne**

1. Ouvrez _Mini-applications_.
2. Appuyez sur `+` pour ajouter une mini-application.
3. Recherchez _Traducteur hors ligne_ dans la liste des applications.
4. Activez-la.

![Étapes d'activation de la mini-application Traducteur hors ligne.](./enable-offline-translator.jpg)

**Comment utiliser le traducteur hors ligne**

1. Appuyez sur le nom de la langue en haut pour changer de langue.
2. Recherchez la paire de langues souhaitée.
3. La fonction de traduction est similaire à Google Traduction et aux autres applications de traduction. Activez _Traduire automatiquement votre chat_ en bas.
4. En général, votre modèle d'IA — le LLM — utilise l'anglais. Configurez le traducteur pour traduire automatiquement votre message, par exemple du français vers l'anglais pour l'IA, puis traduire automatiquement la réponse de l'IA dans votre langue. _Vérifiez que vous avez téléchargé le modèle de traduction en appuyant sur l'icône de téléchargement en forme de nuage._

![Paramètres du traducteur hors ligne permettant de traduire automatiquement les deux côtés d'une conversation.](./use-offline-translator.jpg)

Vous obtenez alors un chat traduit automatiquement.
