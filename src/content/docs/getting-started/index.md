**Layla is an AI assistant for Android or iOS that can use cloud AI models or run a local LLM directly on your phone.** This guide takes you through the initial setup, your first chat, and the choice between cloud and offline AI. You do not need to configure everything at once, and none of the choices you make during onboarding are permanent.

## Choose how you want to use Layla

When you first open Layla, the app asks what you would like to use it for. Each option prepares a different starting configuration:

- **Basic:** Start with a fast, focused offline chatbot and a lightweight local model. Extra features are left switched off, making this a good choice if you want to begin with simple AI chat and add capabilities later.
- **Assistant:** Set up Layla as a private AI personal assistant for chatting, planning, and everyday tasks. This mode includes on-device Agents, which can use tools and follow multi-step instructions rather than only generating a conversational reply.
- **Friend:** Create a personal AI companion for casual conversation, reflection, or simply having someone to talk to. The recommended setup focuses on companion features such as memory, voice, and Dreams so conversations can feel more continuous and personal.
- **Roleplay:** Begin with the features needed to create characters, build scenarios, and run story-driven conversations. You can take part yourself or let multiple AI characters interact, while memory helps maintain the context of the scene.
- **Image generation:** Prepare Layla to turn prompts into images on your device. You can generate standalone images or use them while creating original characters, scenes, and stories.
- **Cloud:** Use hosted AI models when you want more scale and capability without relying on your phone's hardware to run the model. Cloud requests are sent to the selected provider, so this option has different privacy and connectivity considerations from running a local model.
- **Expert:** Bring your own GGUF model and choose exactly which features, tools, prompts, and advanced settings are active. This is intended for local LLM users who already know how they want their inference setup configured.

Choose whichever option is closest to what you want to try first. Layla will set itself up with the features and mini-apps recommended for that use case. This gives you a useful starting point without asking you to understand every setting before you begin.

You are not locked into the use case you select. You can enable or disable features, change mini-apps, and adjust how Layla runs at any time later.

## Start your first chat

What you see next depends on the use case you selected. Layla will show either the welcome screen or the character selection screen.

### From the welcome screen

If you see Layla's welcome screen, tap the large butterfly under **Tap to chat**. This opens a conversation with Layla so you can send your first message.

![Layla welcome screen with the large Tap to chat butterfly.](./welcome.jpg)

### From the character selection screen

Some use cases open the character selection screen instead. Choose the character or personality you want to talk to, then start chatting.

![Character selection screen in Layla, showing Layla and several character collections.](./character-selection.jpg)

The basic chat and character experience will feel familiar if you have used character chat apps such as Character.AI: choose who you want to talk to, type a message, and continue the conversation. Layla also gives you much more control, but you can leave those options alone until you are ready to explore them.

## Choose between Layla Cloud and a local LLM

After you exchange a few messages, Layla will ask how you want to continue. You have two choices:

- **Layla Cloud:** Log in and continue with a cloud model. You do not need to download a model to your phone.
- **Run on your phone:** Choose a local model and run it privately on your device. This option does not require a login or an internet connection after setup, but local AI works best on a phone with capable hardware and enough free storage for the model.

![Layla prompt for choosing between Layla Cloud and a private local model.](./choose-cloud-or-local.jpg)

There is no permanent commitment here either. You can begin with a cloud model for a quicker setup, move to a local LLM for private offline AI, or switch between available models as your needs change.

## Change your model later

You can return to **Inference Settings** whenever you want to change how Layla generates responses. This is where you can manage local GGUF models, supported on-device models, cloud models, prompts, vision models, and image generation settings.

![Inference Settings in Layla, where local and cloud AI models can be managed.](./inference-settings.jpg)

If a local model is slow or does not fit comfortably on your device, you can switch back to a cloud model. If you later get a suitable local model, you can select it without repeating the rest of the onboarding process.

## Explore features and mini-apps at your own pace

Layla can do considerably more than basic AI chat, which can make the app feel overwhelming when you first open it. You do not need to learn everything immediately. Start with chatting or characters, then enable different features and mini-apps one at a time as you need them.

The **Apps** screen is where you can browse and manage mini-apps for features such as characters, the inference engine, Agents, Layla Cloud, and more. For a step-by-step explanation, see [How to enable or disable mini-apps within Layla](/how-to-enable-disable-mini-apps-within-layla/).

![Layla Apps screen showing installed features and mini-apps.](./mini-apps.jpg)

Your initial use case is only a starting configuration. You can turn Layla into a straightforward AI assistant, a character chat app, an image generation tool, a private AI chatbot that runs on your phone, or a combination that suits you.

Have fun exploring all that Layla has to offer.
