Layla is an AI assistant designed to run models directly on your device. This guide establishes the structure for the full installation article.

## Before you begin

Make sure your device has enough free storage for the app and the model you plan to download.

## Install Layla

Download Layla from the official store for your device, then follow the setup instructions shown in the app.

## Start your first conversation

Choose a model, create or select a character, and send a message. Once the model is available locally, the conversation can run without sending its contents to a remote inference service.
