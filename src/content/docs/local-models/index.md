Layla can use compatible language models stored on your device. Local processing keeps model inference available without relying on a continuous internet connection.

## Choose a model

Model size, quantization, and context length all affect memory use and performance. Start with a model recommended for your device class.

## Download the model

Keep Layla open during the initial download. The model will appear in your local model list when the download is complete.

## Check performance

If generation is slow or the app closes unexpectedly, select a smaller model or reduce the configured context length.
