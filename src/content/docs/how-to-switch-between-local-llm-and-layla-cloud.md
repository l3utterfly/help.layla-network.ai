Sometimes you may see this error:

![Layla Cloud error saying that you must log in through the Layla Cloud app.](/assets/articles/how-to-switch-between-local-llm-and-layla-cloud/layla-cloud-login-error.png)

This happens if you have enabled Layla Cloud.

**If you are using Layla Lite**

To switch back to local LLMs that run on your device, uninstall the Layla Cloud mini-app within Layla:

1. Go to *My Apps* from the main screen with the large butterfly.
2. Tap the minus icon in the top-right corner of the apps area.
3. Remove the Layla Cloud app.

**If you are using Layla (paid)**

1. Go to the Inference Settings app.
2. Choose a local LLM model.
