この機能について詳しくは、[Laylaの長期記憶の仕組み](https://www.layla-network.ai/post/how-does-long-term-memory-work-in-layla)をご覧ください。

この記事で説明しているように、長期記憶はバックグラウンドで構築されます。

AndroidやiOSなどの最新のモバイルOSでは、アプリがバックグラウンドで使用できる処理能力が厳しく制限されています。

取り込みを速くするには、次の方法を試してください。

1. Androidの設定で、Laylaに*バックグラウンドでの使用を制限しない*権限を付与します。
2. Androidの設定で、Laylaの*バッテリー最適化*を無効にします。
3. iOSの設定で、Laylaのバックグラウンド更新権限を有効にします。

Laylaで長期記憶アプリを直接開き、*取り込む*をタップすることもできます。

会話を確実に取り込むため、毎晩寝る前に実行できます。このボタンを押すと取り込み処理が開始され、処理する会話がなくなるまで続きます。

寝る前にアプリをフォアグラウンドで開いたままにすることも効果的です。OSはフォアグラウンドのアプリにより多くの処理能力を割り当てます。

**重要：どの方法を使用する場合でも、処理を実行できるようにLaylaをバックグラウンドで動作させてください。アプリを終了しないでください。**
