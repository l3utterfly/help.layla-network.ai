Laylaには、**オフライン翻訳**というミニアプリがあります。

小さな言語モデルを使用し、インターネット接続なしで、スマートフォン上だけで言語間のテキスト翻訳を行います。

会話をリアルタイムで翻訳できる速さがあるため、メインのチャットAIに英語のLLMを使用している場合でも、入力と出力を別の言語へスムーズに翻訳できます。

**オフライン翻訳アプリを有効にする方法**

1. *ミニアプリ*を開きます。
2. `+`をタップしてミニアプリを追加します。
3. アプリの一覧で*オフライン翻訳*を検索します。
4. 有効にします。

![オフライン翻訳ミニアプリを有効にする手順。](./enable-offline-translator.jpg)

**オフライン翻訳の使い方**

1. 上部の言語名をタップして言語を切り替えます。
2. 使用する言語の組み合わせを検索します。
3. 翻訳機能はGoogle翻訳などの翻訳アプリと同様に動作します。下部にある*チャットを自動翻訳*を有効にします。
4. 通常、AIモデル（LLM）は英語を使用します。日本語などの入力をAI向けに英語へ自動翻訳し、AIの出力を日本語へ自動的に戻すよう設定します。_雲形のダウンロードアイコンをタップし、翻訳モデルをダウンロードしておいてください。_

![チャットの入出力を自動翻訳するオフライン翻訳の設定。](./use-offline-translator.jpg)

これでチャットが自動的に翻訳されます。
