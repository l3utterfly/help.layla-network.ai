次のエラーが表示される場合があります。

![Layla Cloudアプリからログインする必要があることを示すLayla Cloudエラー。](./layla-cloud-login-error.png)

これは、Layla Cloudが有効になっている場合に発生します。

**Layla Liteを使用している場合**

デバイス上で動作するローカルLLMに戻すには、Layla内でLayla Cloudミニアプリをアンインストールします。

1. 大きな蝶が表示されるメイン画面で、*マイアプリ*を開きます。
2. アプリ領域の右上にあるマイナスアイコンをタップします。
3. Layla Cloudアプリを削除します。

**Layla（有料版）を使用している場合**

1. 推論設定アプリを開きます。
2. ローカルLLMモデルを選択します。
