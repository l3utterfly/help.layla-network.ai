**はい。Laylaのチャットでは、各メッセージを個別に編集、再生成、コピー、削除、翻訳、読み上げなどができます。メッセージを長押しするか、オーバーフローメニューをタップして操作メニューを開きます。** すべての操作がすべてのメッセージに適用されるわけではありません。自分のメッセージだけに適したものと、Laylaの返信だけに使えるものがあります。

このガイドでは、各操作の内容と対象を説明します。Laylaは完全に端末上で動作するため、編集や再生成を含むすべての操作がローカルで行われ、外部に送信されることはありません。

## メッセージ操作メニューを開く方法

1つのメッセージの操作を表示する方法は2つあります。

- **メッセージの吹き出しを長押しする。** 自分またはLaylaのメッセージを操作メニューが表示されるまで押し続けます。チャット画面全体で使える基本操作です。
- **オーバーフローメニューをタップする。** 一部のメッセージでは吹き出し付近に小さな3点アイコンが表示されます。長押しせずに同じ操作を開けるため、対象を正確に選ぶときに便利です。

![アシスタントからの返信が表示されたダークモードのLaylaチャット。](./open-message-actions.gif)

メニューはメッセージに応じて変わります。自分のメッセージでは、編集、コピー、削除、引用、ピン留め、分岐など入力に適した操作が表示されます。Laylaの返信では、再生成や再試行などの生成操作が加わります。表示されない操作は、その種類のメッセージでは利用できません。

| 操作       | 内容                                               | 対象                          |
| ---------- | -------------------------------------------------- | ----------------------------- |
| Edit       | メッセージのテキストをその場で変更する             | 自分のメッセージとLaylaの返信 |
| Regenerate | 返信の新しいバージョンを生成する                   | Laylaの返信                   |
| Continue   | 途中で切れた可能性があるメッセージを続ける         | Laylaの返信                   |
| Copy       | メッセージのテキストをクリップボードにコピーする   | すべてのメッセージ            |
| Delete     | メッセージを会話から削除する                       | すべてのメッセージ            |
| Speak      | 現在のテキスト読み上げ音声でメッセージを読み上げる | すべてのメッセージ            |

## メッセージを編集する

編集すると、最初からやり直さずにメッセージのテキストを変更できます。メッセージを長押しして **Edit** をタップし、テキストを変更して確定します。

会話の両側で編集できます。一般的なのは、入力ミスの修正、プロンプトの明確化、質問内容の変更のために**自分のメッセージ**を編集し、再送信してLaylaに修正版へ応答させる方法です。**Laylaの返信**の編集はロールプレイや執筆に役立ちます。気に入った部分を残し、全体を再生成せずに残りを手動で調整できます。

![Copy、Edit、Regen、Continue、Delete、Speakが表示されたLaylaのメッセージメニュー。](./edit-message.gif)

過去の自分のメッセージを編集して再送信しても、それ以降の返信は元の文面を基にしています。編集した位置によっては、会話の整合性を保つためにLaylaの次の返信を再生成してください。

## 応答を再生成または再試行する

**Regenerate** は、返信の新しいバージョンを生成するようLaylaに依頼します。応答が適切でなければ長押しして **Regenerate** をタップしてください。プロンプトを書き直さずに出力品質を改善する主な方法です。

再生成した返信は通常、切り替え可能な候補として保存されます。元の返信を失わず、新しいバージョンと比較して好きなものを選べます。

![再生成されたアシスタントの返信を示すLaylaチャット。](./regenerate-message.gif)

生成は端末上で行われるため、再生成や再試行の速度はネットワーク接続ではなく、スマートフォンのハードウェアと読み込んだモデルのサイズによって決まります。

## メッセージを削除する

削除すると会話から1件のメッセージが取り除かれます。メッセージを長押しし、**Delete** をタップして確定します。会話全体や履歴全体の消去とは異なり、選択したメッセージだけが対象です。

会話のやり直し部分、重複した返信、コンテキストに残したくないメッセージを整理できます。モデルは次の発言を決めるために会話履歴を読むので、不要なメッセージを削除するとコンテキストも整います。削除はローカルかつ永続的で、後から復元できません。

> **注：** 会話の以前のメッセージを削除するとチャットが再読み込みされ、モデルは削除した位置から処理を再開します。位置によっては時間がかかる場合があります。

## 会話を分岐する

**Branch** は現在のメッセージから会話を分岐させ、元の会話を失わずに別の流れを試せるようにします。分岐点から新しい経路が作られ、異なる方向、表現、結果を試しても元の会話はそのまま残ります。

![以前のメッセージから分岐したLaylaの会話。](./branch-conversation.gif)

分岐は、同じ場面の異なる展開を試したいロールプレイや執筆に特に適しています。最初の方法を捨てずに別の方法を試す生産性タスクにも使えます。1つの経路を上書きするのではなく、両方を保持できます。

## よくある質問

### 自分のメッセージだけでなく、Laylaの返信も編集できますか？

両方を編集できます。自分のメッセージを編集することが一般的ですが、Laylaの返信もその場で編集し、大部分を残して一部だけを手動調整できます。

### 再生成すると古い応答は削除されますか？

いいえ。再生成した返信は切り替え可能な候補として保持されるため、以前の返信を失わずに比較して選べます。

### 削除したメッセージを復元できますか？

いいえ。削除はローカルかつ永続的です。後で必要になる可能性がある場合は削除しないでください。

### 元の会話を失わずに分岐できますか？

はい。選択したメッセージから別の経路を作り、元の会話を戻れる状態で保持します。

### メッセージ操作はオフラインで動作しますか？

はい。Laylaは端末上で動作するため、編集、再生成、コピー、削除などすべての操作がインターネット接続なしでローカルに行われます。

メッセージ操作は、端末内アシスタントを日常的に使いやすくします。プロンプトの編集、返信の再生成、会話の分岐はすべて手元のハードウェア上で行われ、データが端末外へ出ることはありません。
