Laylaは会話を自動的に**履歴**画面へ保存するため、最初からやり直さずに以前のチャットへ戻れます。履歴画面では、会話の検索、コピーのエクスポート、完全な削除を行えます。

このガイドでは、Laylaの会話履歴を管理する方法と、チャットを削除したときのデータの扱いを説明します。

> **注意：** メニュー名やボタンの位置は、Laylaのバージョンやデバイスによって少し異なる場合があります。

## 会話履歴を開く

以前の会話を表示する手順は次のとおりです。

1. **Layla**を開きます。
2. 左からスワイプするか時計アイコンを使用して、メインナビゲーションメニューを開きます。
3. **履歴**を選択します。
4. 会話をタップして開きます。

進行中の会話には、タイトル、キャラクターまたはアシスタント、最新メッセージのプレビュー、最近のアクティビティの日付が表示されます。

![右上に履歴アイコンがある暗色のLaylaアプリホーム画面。](./open-history-navigation.gif)

![会話履歴を開く方法を示すLaylaアプリのホーム画面。](./open-history-screen.gif)

既存の会話を開くと、以前のメッセージと設定を維持したままチャットを続けられます。

## Laylaの会話履歴を検索する

履歴画面上部の検索バーを使って、特定の会話を探します。

Laylaは次の情報を検索できます。

- 会話のタイトル
- キャラクターまたはアシスタントの名前
- メッセージ内の単語やフレーズ
- 会話のタグまたはカテゴリー

チャットを検索する手順は次のとおりです。

1. **履歴**を開きます。
2. **検索**フィールドをタップします。
3. タイトル、キャラクター名、キーワード、またはフレーズを入力します。
4. 結果を選択して会話を開きます。

入力中に検索結果が更新されるため、通常は単語やタイトルの一部を入力するだけで十分です。

![蝶のアバター、検索バー、情報および削除アイコン付きの2件のLaylaチャットが表示された暗色のメッセージ画面。](./search-history.gif)

## 会話を削除する

会話を削除すると、進行中またはアーカイブ済みの履歴から取り除かれ、**最近削除した項目**へ移動します。

会話を削除する手順は次のとおりです。

1. **履歴**を開きます。
2. 会話の**ゴミ箱**アイコンをタップします。
3. 削除を確認します。

## Laylaは会話履歴をどのくらい保持しますか？

保持方法は会話の状態によって異なります。

| 会話の状態     | 保持方法                                       |
| -------------- | ---------------------------------------------- |
| 進行中         | アーカイブまたは削除するまで履歴画面に残ります |
| 完全に削除済み | すぐに削除され、復元できません                 |

## Laylaをアンインストールまたはデータを消去するとどうなりますか？

次の操作を行うと、デバイスにローカル保存された会話履歴が失われる場合があります。

- Laylaをアンインストールする
- アプリのストレージまたはアプリデータを消去する
- デバイスを初期化する
- OSからLaylaのデータを削除する
- データを転送または復元せず別のデバイスへ移行する

アプリのアンインストール、データ消去、デバイス移行を行う前に、重要な会話をエクスポートするかバックアップを作成してください。

データをバックアップしている場合は、利用可能な会話を復元できることがあります。バックアップの作成前に完全削除されたチャットは復元できません。

## よくある質問

### Laylaは会話を自動的に保存しますか？

はい。チャット中の会話は自動的に履歴画面へ追加されます。会話ごとに手動保存する必要はありません。

### 古い会話を続けられますか？

はい。履歴から会話を開いて新しいメッセージを送信してください。Laylaは利用可能な履歴と設定を引き続き使用します。

### 以前のチャット内を検索できますか？

はい。履歴の検索フィールドを使い、タイトル、キャラクター、アシスタント、キーワード、メッセージ内容から会話を検索できます。

### 完全に削除したチャットを復元できますか？

いいえ。完全削除は元に戻せません。別途保存したエクスポートやバックアップが残っている場合はありますが、Laylaは会話履歴から完全削除されたコピーを復元できません。

### 会話をエクスポートするとLaylaから削除されますか？

いいえ。エクスポートは別のコピーを作成し、元の会話は変更しません。

### キャラクターを削除すると、そのキャラクターとの会話もすべて削除されますか？

はい。キャラクターを削除すると、そのキャラクターに関連付けられた会話履歴と記憶がすべて削除されます。

## 重要な会話を保護する

後で必要になる可能性があるチャットでは、次の操作を検討してください。

- 会話に明確で検索しやすいタイトルを付けます。
- 元の会話を削除する前に、別のコピーをエクスポートします。

独立したバックアップが必要な場合はエクスポートが適しています。完全削除は、不要であることが確実な会話だけに使用してください。
