モデルの読み込み中や更新後に、次のようなエラーが表示される場合があります。

![Laylaのモデル読み込み中に表示されたREPLエラー。](./model-load-error.png)

通常は、*設定*ページを開いて下にスクロールし、*キャッシュを消去*を選択すると、このエラーを解決できます。

モデルやアプリの再ダウンロードが必要になることはほとんどありません。キャッシュを消去すると、アプリをクリーンな状態にリセットできます。

注意：キャッシュを消去した後は、初回のみキャラクターの読み込みに時間がかかります。
