Laylaでは、機能が「ミニアプリ」として整理されています。ミニアプリは、Laylaに追加して使い方をカスタマイズできる独立したモジュールです。

必要に応じて追加や削除を行い、自由に組み合わせて自分に合ったLaylaを構成できます。

**注意：1回限りの購入ですべてのミニアプリが永久にアンロックされます。削除した後でも、追加料金なしで再度追加できます。**

ミニアプリは次のいずれかの方法で探して追加できます。

1. 最初の画面で、大きな青い蝶のアイコンの下にある2番目の項目をタップします。ボタンには**ミニアプリを追加**と表示されます。
2. キャラクター選択画面の右上にあるグリッドアイコンを使用します。歯車アイコンの隣にあります。
