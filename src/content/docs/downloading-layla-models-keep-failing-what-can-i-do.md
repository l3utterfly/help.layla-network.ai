Downloads can fail on a mobile phone for many reasons, including an unstable internet connection or the phone conserving battery by turning off the network.

If a download consistently fails partway through, try the direct download links below:

- **Tiny:** [Qwen1.5-1.8B Layla v4 Q4_K](https://huggingface.co/l3utterfly/Qwen1.5-1.8B-layla-v4-gguf/resolve/main/Qwen1.5-1.8B-layla-v4-Q4_K.gguf)
- **Lite:** [Phi-2 Layla v1 ChatML Q4_K](https://huggingface.co/l3utterfly/phi-2-layla-v1-chatml-gguf/resolve/main/phi-2-layla-v1-chatml-Q4_K.gguf)
- **Q2:** [Mistral 7B Layla v4 ChatML Q2_K](https://huggingface.co/l3utterfly/mistral-7b-v0.1-layla-v4-chatml-gguf/resolve/main/mistral-7b-v0.1-layla-v4-chatml-Q2_K.gguf)
- **Full:** [Mistral 7B Layla v4 ChatML Q4_K](https://huggingface.co/l3utterfly/mistral-7b-v0.1-layla-v4-chatml-gguf/resolve/main/mistral-7b-v0.1-layla-v4-chatml-Q4_K.gguf)

Download the appropriate file with the web browser on your phone. Once it has downloaded, use the *Custom Model* option to load it.
